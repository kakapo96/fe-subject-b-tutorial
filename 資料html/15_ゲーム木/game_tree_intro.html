【科目B対策】データ構造：ゲーム木

ゲーム木は、対戦ゲームにおける「現在の状態」から、プレイヤーと相手が手を選択した結果、どのような「未来の状態」になるかを樹形図（ツリー構造）で表したものです。

テーマ①：Mini-Max法（ミニマックス法）の原則

基本ルール：交互に最善を尽くす

  • 自分（Maxプレイヤー）： 自分のスコアが最も高くなる手を選ぶ。
  • 相手（Minプレイヤー）： 自分のスコアが最も低くなる（自分に不利な）手を選ぶ。
[根] (自分:Max) / \ [A] (相手:Min) [B] (相手:Min) / \ / \ 3 5 2 9

この場合、Aは「3」、Bは「2」を選択します。自分は「3」と「2」を比較し、最大の3を選択します。

テーマ②：α-β法による「枝刈り」

全てのノードを探索すると時間がかかるため、「あ、ここはもう計算する意味がないな」という部分をスキップすることを「枝刈り」と呼びます。

なぜ「枝刈り」ができるのか？

自分（Max）がすでに「値 5」という選択肢を持っているとします。相手の番で、一つ目の選択肢が「2」だった場合、相手（Min）は「2以下」の手を選ぶことが確定します。自分は「5」を持っているため、これ以上この枝を詳しく探索しても、どうせ相手が「2以下」の未来を選んでしまうなら無駄であると判断できます。

テーマ③：再帰による探索ロジック

// ゲーム木を再帰的に探索するイメージ
関数 minimax(node, isMyTurn)
    if (node が葉) return node.評価値

    if (isMyTurn) // 自分の番（Max）
        return max(minimax(child, false) for child in node)
    else          // 相手の番（Min）
        return min(minimax(child, true) for child in node)
関数おわり

【試験のポイント】
1. 下から上に値を戻す： 葉から根に向かって計算を進める。
2. 相手のターンを忘れない： 「自分はMax、相手はMin」を必ず適用する。
3. 枝刈りの条件： 自分の保持する暫定値と比較し、相手がより小さい/大きい値を確定させた瞬間に打ち切る。
