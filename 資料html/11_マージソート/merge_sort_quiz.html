第1問（基礎トレース：併合処理の動き）

マージソートにおける「ソート済みの2つの配列を、1つのソート済み配列にまとめる（併合する）」処理をトレースします。

すでに昇順にソートされた2つの配列 L = {20, 50} と R = {10, 40, 60} があります。これらを空の配列 M に併合します。（要素番号はすべて1から始まるとします）

以下のプログラムの while ループが3回実行し終わった直後の、変数 i と j の値の組み合わせとして正しいものはどれでしょうか。

〇整数型: i ← 1, j ← 1, k ← 1
〇整数型の配列: M

while (i <= Lの要素数 and j <= Rの要素数)
    if (L[i] <= R[j])
        M[k] ← L[i]
        i ← i + 1
    else
        M[k] ← R[j]
        j ← j + 1
    endif
    k ← k + 1
endwhile

第1問 解答と解説

正解： ウ (i = 2, j = 3)

ループごとの変数の変化と配列 M の状態をトレースします。

  • 初期状態: i = 1, j = 1, k = 1
  • 1回目のループ:
    • L[1](20) と R[1](10) を比較。R の方が小さいので else に入る。
    • M[1] ← 10 となり、j が 1 増えて 2 になる。k は 2 になる。
  • 2回目のループ:
    • L[1](20) と R[2](40) を比較。L の方が小さいので if に入る。
    • M[2] ← 20 となり、i が 1 増えて 2 になる。k は 3 になる。
  • 3回目のループ:
    • L[2](50) と R[2](40) を比較。R の方が小さいので else に入る。
    • M[3] ← 40 となり、j が 1 増えて 3 になる。k は 4 になる。

3回目のループ終了直後、配列 M は {10, 20, 40} となり、インデックスは i = 2, j = 3 となっています。

第2問（発展トレース：分割と併合の全体像）

マージソートは、配列を「要素数が1になるまで半分ずつに分割」し、その後「ソートしながら併合（マージ）」していくアルゴリズムです。

配列 data = {50, 20, 60, 10, 40, 30} に対してマージソートを実行します。

分割処理がすべて終わり、小さな配列同士を併合していく過程で、一番最後の併合処理（元の配列サイズに戻る最後の一歩）に入る直前の、2つに分かれた配列の状態として正しいものはどれでしょうか。

第2問 解答と解説

正解： ア ({20, 50, 60} と {10, 30, 40})

マージソートの全体構造（分割と併合）をイメージします。

  1. 【分割フェーズ】
    まずは配列を大きく2つのグループ（左半分と右半分）に分けます。
    左側：{50, 20, 60}
    右側：{10, 40, 30}
    （これらはさらに要素が1つになるまで細かく分割されます）
  2. 【併合フェーズ】
    要素が1つになった状態から、隣り合う要素同士をソートしながら併合していきます。
    左側のグループ {50, 20, 60} は、内部で併合処理が行われ、最終的に {20, 50, 60} というソート済みの状態になります。
    右側のグループ {10, 40, 30} も同様に内部で併合され、{10, 30, 40} となります。

一番最後の併合処理とは、この「完全にソートされた左半分の配列」と「完全にソートされた右半分の配列」を合わせる処理のことです。
したがって、直前の状態は {20, 50, 60} と {10, 30, 40} になります。

第3問（本番レベル・穴埋め）

第1問の併合処理（whileループ）では、配列 L と R の要素を比較し、小さい方から順に M に格納していきました。

しかし、どちらかの配列の要素をすべて M に格納し終えると、条件 i <= Lの要素数 and j <= Rの要素数 が偽となり、ループを抜けてしまいます。このとき、もう片方の配列にはまだ要素が残っている可能性があります。

残りの要素をすべて M に追加するための、以下のプログラムの空欄 [ a ] に入る適切な条件式を選んでください。

// メインの比較ループ（第1問と同じ）
while (i <= Lの要素数 and j <= Rの要素数)
    // 比較してMに格納する処理（省略）
endwhile

// Lの要素がまだ残っている場合、残りをすべてMに追加する
while ( [  a  ] )
    M[k] ← L[i]
    i ← i + 1
    k ← k + 1
endwhile

// Rの要素が残っている場合の処理（省略）

第3問 解答と解説

正解： エ (i <= Lの要素数)

配列 L に要素が残っているかどうかは、L を参照するためのインデックス i が、L の要素数を超えているかどうかで判断できます。

メインのループを抜けた時点で、もし j が Rの要素数 を超えていた（Rの要素をすべて使い切った）場合、i はまだ Lの要素数 以下のはずです。このとき、配列 L の残りの要素をそのまま配列 M の後ろにくっつける処理が必要になります。

したがって、「i が Lの要素数 以下である間（＝Lに未処理の要素が残っている間）」ループを回すため、条件式は i <= Lの要素数 となります。

※すでに配列 L はソートされているため、残っている要素はそのままの順番で M に追加して問題ありません。
