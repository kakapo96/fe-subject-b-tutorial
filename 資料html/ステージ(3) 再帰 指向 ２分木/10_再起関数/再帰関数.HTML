第1問（基礎トレース）

以下のプログラムを実行したとき、最終的な変数 ans の値はどうなるか。

関数 func(整数型: N) 戻り値: 整数型
    if (N <= 1)
        return 1
    endif
    return N + func(N - 1)
関数おわり

// メイン処理
〇整数型: ans
ans ← func(4)

第1問 解答と解説

正解： エ (10)

再帰関数 func(4) の呼び出しをトレース（追跡）します。引数 N が1以下になるまで「待機状態」のまま奥へ進んでいきます。

【行き（もぐる）】
func(4) = 4 + func(3)
  func(3) = 3 + func(2)
    func(2) = 2 + func(1)
      func(1) = 1 // ここでストッパー発動！

一番奥の func(1) が 1 を返したので、そこからドミノ倒しのように逆算していきます。

【帰り（逆算する）】
    func(2) = 2 + 1 = 3
  func(3) = 3 + 3 = 6
func(4) = 4 + 6 = 10

よって、func(4) の結果は 10 となります。

第2問（発展トレース）

以下のプログラムを実行したとき、最終的な変数 ans の値はどうなるか。

関数 calc(整数型: N) 戻り値: 整数型
    if (N <= 1)
        return 1
    endif
    return N * calc(N - 2)
関数おわり

// メイン処理
〇整数型: ans
ans ← calc(5)

第2問 解答と解説

正解： エ (15)

今回の漸化式は N * calc(N - 2) となっており、「足し算」ではなく「掛け算」、そして引数の減り方が「-1」ではなく「-2」になっている点に注意してトレースします。

【行き（もぐる）】
calc(5) = 5 * calc(3) // 引数は 5 - 2 = 3 になる
  calc(3) = 3 * calc(1)
    calc(1) = 1 // 引数が1以下なのでストッパー発動

底に到達したので、掛け算をしながら戻ります。

【帰り（逆算する）】
  calc(3) = 3 * 1 = 3
calc(5) = 5 * 3 = 15

（※もし引数が N - 1 であれば 5*4*3*2*1=120 になりますが、今回は N - 2 なので奇数だけが掛け合わされ、答えは 15 になります。）

第3問（本番レベル・穴埋め）

1からNまでの整数の和を計算する関数 sum を作成したい。プログラム中の空欄 [　a　] と [　b　] に入る条件・式の組み合わせとして、適切なものはどれか。

// 1からNまでの整数の和を計算する関数
関数 sum(整数型: N) 戻り値: 整数型
    // 終了条件（ストッパー）
    if ( [　a　] )
        return 1
    endif
    
    // 再帰呼び出し
    return N + sum( [　b　] )
関数おわり

第3問 解答と解説

正解： ウ

再帰関数の「2つの絶対ルール」を確認する問題です。

  • 空欄 [ a ] （ストッパー）：
    return 1 を返すのは、一番最後の足し算である「1」の時です。したがって、N が1（またはそれ以下）になったときに止める必要があります。よって N <= 1 が適切です。（N >= 1 だと、最初に呼び出した瞬間に終了してしまいます）
  • 空欄 [ b ] （漸化式）：
    自分自身を呼び出すときは、必ずストッパー（今回は1）に向かって進むように引数を変化させる必要があります。現在の数字 N からストッパーの「1」に向かうには、引数を1つずつ減らしていく N - 1 を渡すのが正解です。（N + 1 だと永遠にストッパーに辿り着かず無限ループになります）

※なお、選択肢 オ（N == 0）をストッパーにした場合、0のときに1を返してしまうため、本来の和よりも結果が大きくなってしまうバグが発生します。
