【科目B対策】文法ルール：オブジェクト指向

アルゴリズムの計算とは異なり、オブジェクト指向は「プログラムの部品のまとめ方・書き方のルール」です。
最近の試験（特にサンプル問題以降）では、この記法を使った問題が当たり前のように出題されます。難しい計算はないので、「ドット（.）の意味」と「設計図と実体の違い」だけを理解しましょう。

テーマ：「車の設計図」と「工場で作られた実体」

プログラムの中で、データ（変数）とそれを操作する処理（関数）をバラバラに書くのではなく、「ひとつのセット」としてまとめる考え方がオブジェクト指向です。

絶対に覚えるべき３つの用語

  • クラス（Class）： 属性（データ）と操作（処理）をまとめた「設計図」のこと。
  • インスタンス（Instance）： 設計図をもとに、メモリ上に実際に作られた「実体（オブジェクト）」のこと。
  • メソッド（Method）： クラスの中に定義された「処理（関数）」のこと。

【例え話】 「車クラス」から「車A」を作る

  • クラス（設計図）：車
    ・データ： 現在のスピード
    ・メソッド： 加速する()、ブレーキをかける()
  • この設計図だけでは、乗ることも走ることもできません。工場で実体を作る必要があります。
  • インスタンス（実体）：車A、車B
    プログラム上で「車クラスから、車Aを作れ！」と命令すると、個別のデータを持てる実体が生まれます。
    ・車Aのスピードは 50km/h
    ・車Bのスピードは 0km/h （別々に管理される）

本番形式：クラスとメソッドの擬似言語

試験では、最初に「クラスの定義（設計図）」が書かれており、その後にメイン処理で「実体を作って、ドット（.）でメソッドを呼び出す」という構成になります。

// ==========================================
// ① クラス（設計図）の定義
// ==========================================
クラス Car
    〇整数型: speed          // 車が持つデータ（属性）
    
    // 【コンストラクタ】実体が作られた時に最初に1回だけ自動で呼ばれる処理
    〇Car(整数型: initialSpeed)
        speed ← initialSpeed // 最初のスピードを設定
    
    // 【メソッド】車が持つ操作（関数）
    〇手続き accelerate(整数型: value)
        speed ← speed + value  // スピードを上げる
    
    〇関数 getSpeed() 戻り値: 整数型
        return speed           // 今のスピードを教える
クラスおわり


// ==========================================
// ② メイン処理（設計図を使って実際に動かす場所）
// ==========================================
〇Car: myCar                 // Car型の変数「myCar」を用意

// インスタンス（実体）を生成し、初期スピード0を渡す
myCar ← Car(0)

// 「ドット（.）」を使って、myCarのメソッドを呼び出す！
myCar.accelerate(50)         // myCarを50加速させる

〇整数型: current
current ← myCar.getSpeed()   // 現在のスピード（50）を取得
// 出力: 50

本番の試験で「穴埋め」にされるポイント

オブジェクト指向の文法問題で問われるのは、複雑なアルゴリズムではなく「どの実体の、どの処理を呼び出しているか」という書き方のルールです。

狙われるポイント①：インスタンスの生成（実体化）

空欄の例
myCar ← [　a　]
正解
Car(0)
なぜ？
設計図（クラス）から実体を作る際、クラス名と同じ名前の特別な関数「コンストラクタ」を呼び出します。ここでカッコ内に引数（この場合は初期スピードの0）を渡すことで、初期状態がセットされた実体が完成します。

狙われるポイント②：ドット（.）を使ったメソッド呼び出し

空欄の例
current ← [　b　]
正解
myCar.getSpeed()
なぜ？
オブジェクト指向の最も重要なルールです。「誰の」処理を実行するのかを明確にするため、実体名.メソッド名() という形でドット（.）で繋ぎます。単に getSpeed() と書いただけでは、どの車のスピードか分からないためエラーになります。

【試験で1秒で見抜くコツ】
プログラムの中に A.hoge() のような「ドット（.）で繋がれた関数」が出てきたら、「あ、これはオブジェクト指向の書き方で、Aという実体のhogeという操作をしているんだな」と翻訳して読んでください。これだけでパニックにならずに済みます！
