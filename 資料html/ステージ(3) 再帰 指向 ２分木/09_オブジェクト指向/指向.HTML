第1問（基礎トレース：インスタンスの生成）

以下のプログラムを実行したとき、最終的な変数 ans の値はどうなるか。

クラス Player
〇整数型: hp
// コンストラクタ
〇Player(整数型: initialHp)
    hp ← initialHp
    
〇関数 getHp() 戻り値: 整数型
    return hp

クラスおわり
// メイン処理
〇Player: p1
〇整数型: ans
p1 ← Player(100)
ans ← p1.getHp()

第1問 解答と解説

正解： エ (100)

オブジェクト指向における「設計図（クラス）」から「実体（インスタンス）」を作り出し、値を読み取る基本操作です。

  • p1 ← Player(100) : ここで Player クラスのコンストラクタが呼び出されます。引数として 100 が渡されるため、実体 p1 が持つデータ hp には 100 が代入されます。
  • ans ← p1.getHp() : 「ドット（.）」を使って p1 の getHp() メソッドを呼び出します。このメソッドは現在の hp を返すため、100 が返されます。
  • 結果として、変数 ans には 100 が格納されます。

第2問（発展トレース：メソッドによる状態変化）

以下のプログラムを実行したとき、最終的な変数 ans の値はどうなるか。

クラス BankAccount
〇整数型: balance
〇BankAccount(整数型: initAmount)
    balance ← initAmount
    
〇手続き deposit(整数型: amount)
    balance ← balance + amount
    
〇手続き withdraw(整数型: amount)
    balance ← balance - amount
    
〇関数 getBalance() 戻り値: 整数型
    return balance

クラスおわり
// メイン処理
〇BankAccount: account
〇整数型: ans
account ← BankAccount(1000)
account.deposit(500)
account.withdraw(200)
account.withdraw(100)
ans ← account.getBalance()

第2問 解答と解説

正解： エ (1200)

実体（インスタンス）のデータがメソッドの呼び出しによってどう変化していくかをトレースします。

  • account ← BankAccount(1000) : コンストラクタにより、account の balance（残高）が 1000 で初期化されます。
  • account.deposit(500) : deposit 手続きが呼ばれ、balance は 1000 + 500 = 1500 になります。
  • account.withdraw(200) : withdraw 手続きが呼ばれ、balance は 1500 - 200 = 1300 になります。
  • account.withdraw(100) : 再度 withdraw 手続きが呼ばれ、balance は 1300 - 100 = 1200 になります。
  • 最後に account.getBalance() で現在の balance である 1200 を取得し、ans に代入します。

第3問（本番レベル・穴埋め：複数インスタンスの操作）

以下のプログラムは、2つのロボットの実体（roboA, roboB）を作成し、それぞれの位置を移動させるものです。
実行終了後、変数 posA の値を 5 にし、変数 ans の値を 9 にするためには、空欄 [　a　] に何を入れるべきか。

クラス Robot
〇整数型: x
〇Robot() // コンストラクタ（初期値は0）
    x ← 0
    
〇手続き moveRight(整数型: step)
    x ← x + step
    
〇関数 getPosition() 戻り値: 整数型
    return x

クラスおわり
// メイン処理
〇Robot: roboA
〇Robot: roboB
〇整数型: posA, posB, ans
roboA ← Robot()
roboB ← Robot()
roboA.moveRight(3)
roboB.moveRight(4)
[　　　a　　　] // ここに命令を追加する
posA ← roboA.getPosition()
posB ← roboB.getPosition()
ans ← posA + posB

第3問 解答と解説

正解： ウ (roboA.moveRight(2))

オブジェクト指向で最も重要な「どの実体（インスタンス）の操作をしているか」を問う問題です。

  • コンストラクタ実行直後、roboA と roboB の位置(x)はそれぞれ別々に 0 で初期化されます。
  • roboA.moveRight(3) により、roboA の位置は 3 になります。
  • roboB.moveRight(4) により、roboB の位置は 4 になります。
  • 問題の条件より、最終的な posA を 5 にする必要があります。現在の roboA の位置は 3 なので、さらに 2 進める必要があります。
  • また、ans は posA + posB であり、5 + 4 = 9 となるため、roboB はこれ以上動かす必要がありません。
  • オブジェクト指向の文法ルールに従い、「roboA を操作する」と明示するためには、ドット（.）を使って roboA.moveRight(2) と書かなければなりません。（ア）のように単に moveRight(2) と書くと、どのロボットを動かすのか分からないためエラーになります。
