【科目B対策】データ構造：連結リスト

配列はデータを「すき間なく順番に」並べる必要がありますが、連結リストはメモリの空いている場所に自由にデータを置き、それらを「ポインタ（矢印）」で数珠つなぎにするデータ構造です。

テーマ①：宝箱と地図（リストの基本構造）

連結リストの基本単位「ノード（節）」

1つの箱（ノード）には、以下の2つが必ずセットで入っています。
① データ本体（値）
② 次のノードの場所を指す矢印（次ポインタ）
※一番最後のノードの矢印は「次はないよ」という意味の null（又は0）になります。

【動きのシミュレーション】 途中にデータを「挿入」する

現在、「A」さんの次に「B」さんが繋がっています。この間に「X」さんを割り込ませます。

  • 初期状態：
    Aさん次: Bへ → Bさん次: null
  • 追加するXさんを準備： Xさん次: ?
  • 手順①（Xの右腕を繋ぐ）： まず、Xさんの「次ポインタ」を、Aさんが元々指していた「Bさん」に向けます。
    Xさん次: Bへ → Bさん次: null
  • 手順②（Aの右腕を繋ぎ変える）： 次に、Aさんの「次ポインタ」を「Xさん」に向けます。
    Aさん次: Xへ → Xさん次: Bへ
  • ※配列のように「後ろの人を全員ズラす」必要がなく、矢印を2本付け替えるだけで一瞬で割り込めるのが連結リストの強みです！

本番形式：リストへの挿入・削除プログラム

試験では、先ほどの「矢印の付け替え」をプログラムでどう書くかが問われます。「代入の順番」が命です。

  • node.val はデータ本体、node.next は次のノードを指すポインタとします。
// 【挿入】 nodeA の直後に newNode を挿入する関数
関数 insertNode(ノード型: nodeA, ノード型: newNode)
    
    // ① まず、新しいノードの矢印を「Aの次（B）」に向ける
    newNode.next ← nodeA.next
    
    // ② 次に、Aの矢印を「新しいノード」に向ける
    nodeA.next ← newNode
    
関数おわり


// 【削除】 nodeA の次にあるノード（B）を削除（スキップ）する関数
関数 deleteNextNode(ノード型: nodeA)
    〇ノード型: targetNode
    
    // 削除対象のノード（B）を特定する
    targetNode ← nodeA.next
    
    // 削除対象が存在すれば、矢印をスキップさせる！
    if (targetNode != null)
        // Aの矢印を、「Bの次（C）」に直接繋ぐ（Bを飛ばす）
        nodeA.next ← targetNode.next
    endif
    
関数おわり

本番の試験で「穴埋め」にされるポイント

連結リストの問題は、ポインタの書き換え順序がすべてです。ここを間違えると「迷子」になります。

狙われるポイント①：挿入時の「順番」の罠

空欄の例
[　a　] ← nodeA.next
nodeA.next ← newNode
正解
newNode.next
なぜ？
もし逆に、先に nodeA.next ← newNode を実行してしまうと、元々Aの次にいた「B」の場所が分からなくなってしまいます（迷子発生！）。
必ず「新しい人の右腕（newNode.next）」を先に繋いでから、「前の人の右腕（nodeA.next）」を切り替えます。

狙われるポイント②：削除（スキップ）の式

空欄の例
（Aの次にあるBを削除する場合）
nodeA.next ← [　b　]
正解
nodeA.next.next （または targetNode.next）
なぜ？
連結リストにおける「削除」とは、データを消しゴムで消すことではなく、「ポインタ（矢印）の宛先を、一つ飛ばして繋ぎ変えること」です。「Aの次」を「Aの次の次」に向けることで、真ん中のノードは誰からも指されなくなり、実質的にリストから消滅します。

🔥 応用・超頻出：「双方向リスト」の場合

解説
これまでは「次（next）」しか知らない単方向リストでしたが、試験（例えば令和5年公開問題の問2）では「次（next）」と「前（prev）」の両方の矢印を持つ「双方向リスト」が頻出します。
双方向リストに割り込む場合、「前の人の次（next）」「後ろの人の前（prev）」という合計2本のポインタが書き換わる点に注意してください。

【暗記ポイント】
連結リストの強みは「データの挿入・削除が速い（矢印を繋ぎ変えるだけ）」こと。
弱みは「n番目のデータを探すのが遅い（先頭から矢印をたどるしかない）」ことです（※配列はその逆）。この特徴の違いは科目Aでも頻出です！
