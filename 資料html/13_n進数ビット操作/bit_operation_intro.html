3. 問6「ビット反転プログラム」の完全理解

関数 rev は、8ビットのデータ（例: 01001011）を逆順（11010010）にするプログラムです。
ここまでに学んだ「シフト」と「ハサミ＆接着剤」のコンボで、この魔法がどうやって起きているのか解剖しましょう。

// 正解のプログラム（ア）
for (i を 1 から 8 まで 1 ずつ増やす)
    r ← (r << 1) ∨ (rbyte ∧ 00000001)
    rbyte ← rbyte >> 1
endfor
★ 解法の結論（1秒で見抜く暗記ポイント）

「結果（r）は左へ（<<）育てて、元データ（rbyte）は右へ（>>）削る！」
矢印の向きが逆（<< と >>）になっている選択肢を探せば一発で解けます。

動きのシミュレーション（なぜこれで逆順になるのか？）

初期状態：
元データ rbyte = [ a b c d e f g h ]
結果の箱 r = [ 0 0 0 0 0 0 0 0 ]

ループ 1回目

① (rbyte ∧ 00000001)
ハサミ（AND）を使って、元データの一番右端「h」だけを切り取ります。
→ [ 0 0 0 0 0 0 0 h ]

② (r << 1)
結果の箱（r）を左に1つズラして、右端に空席を作ります。
→ [ 0 0 0 0 0 0 0 _ ]

③ ① ∨ ②
空けた席に、切り取った「h」を接着剤（OR）で合体させます！
→ r = [ 0 0 0 0 0 0 0 h ]

④ rbyte >> 1
元データを右に1つズラして、次に処理する「g」を一番右端に持ってきます。
→ rbyte = [ 0 a b c d e f g ]

ループ 2回目

同じことを繰り返します。
① 今度は右端に来た「g」をハサミで切り取ります。
② rを左にズラして席を空けます。さっき入れた「h」は左に押し出されます。
   r = [ 0 0 0 0 0 0 h _ ]
③ 空いた席に「g」を合体させます。
   r = [ 0 0 0 0 0 0 h g ]
④ 元データを右にズラして、次は「f」の番です。

8回繰り返すと…？

右から順番に切り取られたデータが、新しい箱の右から入って左へ押し出されていくので、最終的に「完全に逆順」のデータが完成します！
r = [ h g f e d c b a ]

【要点まとめ】
AND(∧)で右端を取り出し、OR(∨)でくっつけ、シフト(<<, >>)でベルトコンベアのように流す。
これがビット操作の黄金パターンです！
