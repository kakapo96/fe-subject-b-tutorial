第1問（10進数からn進数への変換）

10進数の整数 n を k 進数に変換して文字列として出力するプログラムです。以下の空欄 [ a ] に入る適切な式を選んでください。

〇整数型: n, k
〇文字列: result ← ""
while (n > 0)
    // 割り算の余りを文字列の先頭に追加し、商で置き換える
    result ← (n % k) + result
    n ← [  a  ]
endwhile

第1問 解答と解説

正解： ウ (n ÷ k の商)

10進数をn進数に変換する基本アルゴリズムは「基数で繰り返し割り、その余りを下から順に並べる」ことです。

  • プログラムでは余り（n % k）を先に求めています。
  • 次に、次の桁を計算するために n を k で割る必要があります。
  • 整数型同士の演算において「商」を得る操作を行うことで、ループのたびに桁を一つずつずらしていくことができます。

第2問（n進数の加算）

2つの n 進数の整数を足し合わせる処理を考えます。ある桁の足し算で、合計が n 以上になった場合の処理として正しいものはどれでしょうか。

第2問 解答と解説

正解： ウ (n を引き、上の桁に1を繰り上げる)

進数計算のルールは、どの進数でも共通です。

  • 10進数で「合計が10以上になったら10を引いて、上に1繰り上げる」のと同じです。
  • したがって、n 進数の場合は「合計が n 以上になったら n を引いて、上に 1 を繰り上げる」が正解となります。

第3問（実数部の変換）

10進数の小数（例: 0.625）を 2 進数に変換する場合、どのような操作を繰り返せばよいでしょうか。

第3問 解答と解説

正解： イ (2で繰り返し掛ける)

小数部の変換は、整数部の「割り算」とは逆の「掛け算」を行います。

  • 0.625 × 2 = 1.25（整数部 1 が出る）
  • 0.25 × 2 = 0.5（整数部 0 が出る）
  • 0.5 × 2 = 1.0（整数部 1 が出る）
  • これを取り出した整数部を上から順に並べると 0.101 となります。

整数部は「下から」、小数部は「上から」並べるという違いをセットで覚えておくと、試験本番で迷いません。
