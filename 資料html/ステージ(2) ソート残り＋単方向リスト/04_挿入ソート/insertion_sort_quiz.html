第1問（基礎トレース）

要素番号が1から始まる配列 data に初期値として [5, 3, 4, 1, 2] が格納されている。以下の挿入ソートのプログラムを実行したとき、外側のループ（for文）が1周目（i = 2 の処理）を終了した直後の配列 data の状態として正しいものはどれか。

〇整数型の配列: data
〇整数型: i, j, tmp
〇整数型: N

N ← dataの要素数
for (i を 2 から N まで 1 ずつ増やす)
    tmp ← data[i]
    j ← i - 1
    while (j >= 1 and data[j] > tmp)
        data[j+1] ← data[j]
        j ← j - 1
    endwhile
    data[j+1] ← tmp
endfor

第1問 解答と解説

正解： ウ: [3, 5, 4, 1, 2]

挿入ソートは、左端から順に「整列済みエリア」を広げていくアルゴリズムです。外側のループ1周目（i = 2）の動きをトレースします。

  • 初期状態: [5 | 3, 4, 1, 2] (1番目の「5」は整列済みとみなす)
  • i = 2 のとき:
    • tmp ← data[2] により、挿入したい値は 3 となります。
    • j ← 1 となり、左隣の要素（data[1]=5）と比較します。
    • data[1] (5) > tmp (3) が成立するため、whileループに入ります。
    • data[2] ← data[1] により、5が右に1つズレます。配列は一時的に [5, 5, 4, 1, 2] のようになり、j は 0 になります。
    • j >= 1 を満たさなくなり、whileループを終了します。
    • data[0+1] ← tmp により、空いた一番左の場所に 3 が挿入されます。

結果として、1周目終了直後の配列は [3, 5 | 4, 1, 2] となります。

第2問（発展トレース）

第1問と同じく、初期状態の配列 data が [5, 3, 4, 1, 2] であるとする。

プログラム全体が終了し、配列が完全に昇順（[1, 2, 3, 4, 5]）に並び替わるまでの間に、内側のwhileループ内にある「data[j+1] ← data[j]（要素を右へ1つズラす処理）」は合計で何回実行されるか。

第2問 解答と解説

正解： オ: 8回

「邪魔なものを右にズラした回数」をループの周回ごとに数え上げます。

  • 【1周目】i=2 (対象: 3): [5 | 3, 4, 1, 2]
    5 > 3 なので、5を右へズラす。（1回） → [3, 5 | 4, 1, 2]
  • 【2周目】i=3 (対象: 4): [3, 5 | 4, 1, 2]
    5 > 4 なので、5を右へズラす。（1回）
    3 < 4 なので、3はズラさない。 → [3, 4, 5 | 1, 2]
  • 【3周目】i=4 (対象: 1): [3, 4, 5 | 1, 2]
    5 > 1 でズラす、4 > 1 でズラす、3 > 1 でズラす。（3回） → [1, 3, 4, 5 | 2]
  • 【4周目】i=5 (対象: 2): [1, 3, 4, 5 | 2]
    5 > 2 でズラす、4 > 2 でズラす、3 > 2 でズラす。（3回）
    1 < 2 なので、1はズラさない。 → [1, 2, 3, 4, 5]

合計すると 1回 + 1回 + 3回 + 3回 = 8回 となります。

第3問（本番レベル・穴埋め）

以下の擬似言語は、配列 data を昇順（小さい順）に並べ替える挿入ソートのプログラムである。
空欄 [　a　] と [　b　] に入る式の組み合わせとして、適切なものはどれか。

〇整数型の配列: data
〇整数型: i, j, tmp
〇整数型: N

N ← dataの要素数
for (i を 2 から N まで 1 ずつ増やす)
    tmp ← data[i]
    j ← i - 1
    
    // 挿入場所を探しながら、tmpより大きい数を右にズラす
    while (j >= 1 and [　a　])
        data[j+1] ← data[j]
        j ← j - 1
    endwhile
    
    // 避難させていた tmp を空いた隙間に入れる
    [　b　] ← tmp
endfor

第3問 解答と解説

正解： ア: [ a ] data[j] > tmp　　[ b ] data[j+1]

[ a ] について：
昇順（小さい順）に並べるため、いま挿入しようとしている数（tmp）よりも左側にある数（data[j]）が大きい場合、その数は邪魔になります。そのため、data[j] > tmp を条件として、邪魔な数を右へズラし続けます。自分より小さい数にぶつかったらズラすのをやめます。

[ b ] について：
whileループを抜けたときの変数 j は、「tmpよりも小さい数が入っている場所」または「0（左端まで調べ尽くした）」を指しています。
したがって、tmp を入れるべき正しい隙間は、そのすぐ右隣である data[j+1] となります。
