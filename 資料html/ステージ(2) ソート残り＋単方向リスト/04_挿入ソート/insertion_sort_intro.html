科目B対策：挿入ソートの仕組みと擬似言語

テーマ：手札のトランプを並べ替える（挿入ソート）

バラバラに並んだ5つの数字を「小さい順（昇順）」に並べ替えます。
最初の配列： [5, 3, 4, 1, 2]

挿入ソートのたった1つのルール

「配列を『整列済みエリア』と『未整列エリア』に分け、未整列の先頭の要素を、整列済みエリアの正しい場所にスッと差し込む（挿入する）」
最初は「1番目の要素だけ」が整列済みエリアだと見なしてスタートします。

動きのシミュレーション

【1周目】 2番目の要素「3」を挿入する

  • 現在の配列： [5 | 3, 4, 1, 2] （左の5だけが整列済み）
  • 挿入する数 3 を手に取ります。
  • 整列済みエリアの「5」と比べると、3の方が小さいので、5を右にズラして、その空いた場所に3を差し込みます。
  • 結果： [3, 5 | 4, 1, 2]

【2周目】 3番目の要素「4」を挿入する

  • 現在の配列： [3, 5 | 4, 1, 2]
  • 挿入する数 4 を手に取ります。
  • 整列済みエリアを右から見ます。「5」より小さいので5を右にズラす。「3」よりは大きいので、3の右隣に差し込みます。
  • 結果： [3, 4, 5 | 1, 2]

【3周目】 4番目の要素「1」を挿入する

  • 現在の配列： [3, 4, 5 | 1, 2]
  • 挿入する数 1 を手に取ります。
  • 「5」「4」「3」のどれよりも小さいので、全部を右にズラして、一番左端に1を差し込みます。
  • 結果： [1, 3, 4, 5 | 2]

【4周目】 5番目の要素「2」を挿入する

  • 現在の配列： [1, 3, 4, 5 | 2]
  • 挿入する数 2 を手に取ります。
  • 「5」「4」「3」を右にズラし、「1」の右隣に差し込みます。
  • 結果： [1, 2, 3, 4, 5]
    これで完全に並び替わりました！

本番形式：挿入ソートの擬似言語

選択ソートやバブルソートは「単純な入れ替え（スワップ）」をしていましたが、挿入ソートは「邪魔なものを右にズラして、空いた隙間に入れる」という動きをします。そこに着目して読んでください。

  • 配列 data には、バラバラの数字が入っているとします。
  • 配列の要素番号（インデックス）は 1 から始まります。
〇整数型の配列: data
〇整数型: i, j, tmp
〇整数型: N

N ← dataの要素数

// 【外側のループ】 2番目の要素から、順番に手に取っていく
// (1番目は最初から整列済みだと見なすため、2からスタートする)
for (i を 2 から N まで 1 ずつ増やす)
    
    // 手に取った「挿入したい数」を一時的に tmp に避難させておく
    tmp ← data[i]
    
    // j は「整列済みエリアの右端」を指す。ここから左へ向かって調べていく
    j ← i - 1
    
    // 【内側のループ】 挿入場所を探しながら、tmpより大きい数を右にズラす
    // 左端(1番目)を越えないこと、かつ、見ている数がtmpより大きい間繰り返す
    while (j >= 1 and data[j] > tmp)
        
        data[j+1] ← data[j]  // 要素を1つ右へズラす！
        j ← j - 1          // さらに左の要素を見るために j を減らす
        
    endwhile
    
    // ループを抜けたら、そこが「挿入すべき場所（j+1）」！
    // 避難させていた tmp を空いた隙間に入れる
    data[j+1] ← tmp

endfor

本番の試験で「穴埋め」にされるポイント

挿入ソートのプログラムで頻出の空欄ポイントは以下の3箇所です。

狙われるポイント①：外側のループのスタート地点

空欄の例
for (i を [　a　] から N まで 1 ずつ増やす)
正解
2
なぜ？
挿入ソートは「すでに並んでいる部分」に対して、新しい要素を差し込んでいくアルゴリズムです。一番最初の状態では、「左端の1番目の要素だけは、すでに並んでいる（要素1個の整列済み配列）」と見なすため、作業は「2番目の要素」を手に取るところからスタートします。

狙われるポイント②：while文の継続条件（ズラす条件）

空欄の例
while (j >= 1 and [　b　])
正解
data[j] > tmp
なぜ？
昇順（小さい順）に並べたいので、いま手に持っている数（tmp）よりも大きい数（data[j]）が左側にいたら、それは邪魔なので右へズラす必要があります。逆に言えば、tmpより小さい数にぶつかったら、そこが挿入ポイントになるためズラすのをやめます（while終了）。

狙われるポイント③：tmp を挿入する場所

空欄の例
[　c　] ← tmp
正解
data[j+1]
なぜ？
whileループを抜けたときの j は、「tmpよりも小さい数があった場所」か、または「0（端まで調べ尽くした）」になっています。いずれにせよ、tmpが入るべき正しい場所は「そのすぐ右隣（j + 1）」になります。

【試験で1秒で見抜くコツ】
二重ループの内側が while 文になっていて、その中で data[j+1] ← data[j] のように「1つ横にズラす（コピーする）」動きをしていたら、それは「挿入ソート」です！
