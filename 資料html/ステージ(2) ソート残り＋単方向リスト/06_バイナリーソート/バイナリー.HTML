第1問（基礎トレース）

以下のプログラムは、配列 data から変数 target と一致する値を探す2分探索のアルゴリズムです。
配列 data が {10, 30, 50, 70, 90} （要素番号は1から5）、target が 70 であるとき、1回目のループ（while文内の処理）が終了した直後の、変数 low と high の値の組み合わせとして正しいものはどれですか。

〇整数型の配列: data
〇整数型: target
〇整数型: low, high, middle, ans

low ← 1
high ← dataの要素数
ans ← -1

while (low <= high)
    middle ← (low + high) ÷ 2 の商
    if (data[middle] == target)
        ans ← middle
        break
    elseif (data[middle] < target)
        low ← middle + 1
    else
        high ← middle - 1
    endif
endwhile

第1問 解答と解説

正解： ウ (low = 4, high = 5)

変数の変化を順番にトレースします。

  • 初期化処理:
    low = 1
    high = 5 (配列dataの要素数は5)
    ans = -1
  • 1回目のループ:
    low <= high (1 <= 5) は真なのでループに入ります。
    middle = (1 + 5) ÷ 2 の商 = 3
    配列の3番目を確認します。 data[3] は 50 です。
    data[3] (50) == target (70) は偽。
    data[3] (50) < target (70) は真です。
    したがって、elseif のブロックが実行され、low = middle + 1 となります。
    low = 3 + 1 = 4 に更新されます。
    high は更新されないため 5 のままです。

よって、1回目のループ終了直後の値は low = 4, high = 5 となり、探索範囲が右半分に絞り込まれたことがわかります。

第2問（発展トレース）

第1問と同じ2分探索のプログラムを使用します。
配列 data が {15, 25, 35, 45, 55} （要素数5）、探したい値 target が 40 に設定されているとします。
このプログラムを実行し終えたとき、while 文の中の処理（ループ）は合計何回実行されますか。（※配列内に存在しない値を探すケースです）

第2問 解答と解説

正解： イ (2回)

探している値「40」は配列内に存在しません。この場合の指（lowとhigh）の動きをトレースします。

ループ回数 判定前 (low, high) middle data[middle]との比較 判定後 (low, high)
1回目 low=1, high=5 (1+5)÷2 = 3 data[3]は35。
35 < 40 なので右半分へ。		 low=4, high=5
2回目 low=4, high=5 (4+5)÷2 = 4 (端数切捨て) data[4]は45。
45 > 40 なので左半分へ。		 low=4, high=3

3回目のループ突入前の判定：
while (low <= high) の条件式で、low=4, high=3 を評価します。
4 <= 3 は「偽(False)」となるため、ループには入らずに終了します。
最終的に ans は初期値の -1 のままでプログラムが終了します。

したがって、ループ内の処理が実行された回数は2回です。

第3問（本番レベル・穴埋め）

以下のプログラムは、昇順に整列された配列 data から target と一致する要素を2分探索で探すものです。プログラム中の空欄 [ a ] と [ b ] に入れる式の組み合わせとして、適切なものはどれですか。

low ← 1
high ← dataの要素数
ans ← -1

while ( [  a  ] )
    middle ← (low + high) ÷ 2 の商
    if (data[middle] == target)
        ans ← middle
        break
    elseif (data[middle] < target)
        low ← middle + 1
    else
        high ← [  b  ]
    endif
endwhile

第3問 解答と解説

正解： イ

2分探索における重要な「条件」と「範囲の更新」を問う問題です。

  • 空欄 [ a ] について：
    探索を続ける条件は「探索範囲が存在している間」です。
    左の指(low) と 右の指(high) が同じ場所を指している時（low == high）も、その1要素を調べる必要があるため、探索を続ける必要があります。
    左の指が右の指を追い越した時（low > high になった時）に初めて「探索範囲がなくなった（見つからなかった）」と判断してループを抜けます。したがって、正解は low <= high です。

  • 空欄 [ b ] について：
    else ブロックに入るのは、data[middle] > target の場合、つまり「真ん中の値よりも、探している値が小さい」場合です。
    このとき、真ん中(middle)から右側には絶対に答えがないため、探索範囲を「左半分」に絞り込みます。
    すでに調べた middle の場所を再び範囲に含める必要はないため、右の指(high) を真ん中の1つ左、つまり middle - 1 にズラします。
