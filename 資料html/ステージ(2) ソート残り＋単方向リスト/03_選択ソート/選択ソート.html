第1問（基礎トレース）

要素が格納された配列 data = {50, 30, 40, 10, 20} （要素番号は1〜5）に対して、以下の選択ソート（昇順）のプログラムを実行します。

外側の for ループ（変数 i のループ）が1回目の処理を終えた直後の、配列 data の状態として正しいものはどれでしょうか。

〇整数型の配列: data ← {50, 30, 40, 10, 20}
〇整数型: i, j, min_idx, tmp

for i を 1 から (dataの要素数 - 1) まで 1 ずつ増やす
    min_idx ← i
    // 内側のループ：未ソート部分から最小値を探す
    for j を (i + 1) から dataの要素数 まで 1 ずつ増やす
        if (data[j] < data[min_idx])
            min_idx ← j
        endif
    endfor
    // 最小値と未ソート部分の先頭(i番目)を交換
    tmp ← data[i]
    data[i] ← data[min_idx]
    data[min_idx] ← tmp
endfor

第1問 解答と解説

正解： イ ({10, 30, 40, 50, 20})

1回目の外側ループ（i = 1）の処理をトレースします。

  • 初期状態: data = {50, 30, 40, 10, 20}
  • i = 1 のとき、min_idx は最初 1 (値は 50) に設定されます。
  • 内側のループで j を 2 から 5 まで動かし、未ソート部分から最小値を探します。
    • 全体の中で最も小さい値は4番目の 10 なので、内側ループ終了時に min_idx = 4 となります。
  • その後、data[1] (50) と data[4] (10) の値を交換します。
  • 交換後の状態: data = {10, 30, 40, 50, 20}

選択ソートは、このように「未ソート部分から一番小さい要素を見つけて、先頭と交換する」という動作を繰り返します。

第2問（発展トレース）

第1問と同じ配列 data = {50, 30, 40, 10, 20} をソートします。

外側のループ（for i）が2回目の処理を終えた直後の、配列の先頭から2つの要素の組み合わせとして正しいものはどれでしょうか。

第2問 解答と解説

正解： ウ (10, 20)

ループごとの配列の変化を追っていきます。

  • 1回目終了後: {10, 30, 40, 50, 20} （要素 10 が確定）
  • 2回目のループ (i = 2):
    • 今回は2番目の要素（30）以降の未ソート部分 {30, 40, 50, 20} が対象です。
    • min_idx は最初 2 に設定されます。
    • 内側のループで j を 3 から 5 まで動かし、未ソート部分から最小値を探します。最小値は5番目の 20 なので、min_idx = 5 に更新されます。
    • data[2] (30) と data[5] (20) の値を交換します。

2回目終了後の状態: data = {10, 20, 40, 50, 30}
したがって、先頭から2つの要素は 10, 20 となります。

第3問（本番レベル・穴埋め）

ここまでの選択ソートは「昇順（小さい順）」に並べ替えるものでした。
もし配列 data を降順（大きい順）にソートしたい場合、未ソート部分から最小値ではなく「最大値」を探すように条件を変更する必要があります。

※変数名は便宜上 min_idx （ここでは「注目しているインデックス」の意味）のままとします。

以下の降順ソート用プログラムの空欄 [ a ] に入る適切な条件式を選んでください。

for j を (i + 1) から dataの要素数 まで 1 ずつ増やす
    if ( [  a  ] )
        min_idx ← j
    endif
endfor

第3問 解答と解説

正解： イ (data[j] > data[min_idx])

降順（大きい順）に並べ替えるということは、未ソート部分から一番大きい要素を見つけ出し、それを先頭に持ってくる必要があります。

内側のループでは、現在暫定で一番大きいと思っている要素のインデックス（min_idx に格納されている）と、次に比較する要素（data[j]）を比べます。

もし、次に比較する data[j] の方が、現在一番大きいと思っている data[min_idx] よりも大きければ、暫定1位の座を j に譲る（min_idx ← j を実行する）ことになります。

したがって、条件式は「data[j] が data[min_idx] より大きい場合」を表す data[j] > data[min_idx] となります。
