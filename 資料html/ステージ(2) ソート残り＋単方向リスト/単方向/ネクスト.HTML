第1問（基礎トレース：ポインタの追跡）

ノードが val（データ本体）と next（次ポインタ）を持つ単方向の連結リストがある。以下のプログラムを実行した直後、nodeA.next.next.val の値はいくつになるか。

〇ノード型: nodeA, nodeB, nodeC, nodeX
// 各ノードの値を設定
nodeA.val ← 10
nodeB.val ← 20
nodeC.val ← 30
nodeX.val ← 99
// 初期リストの作成 (A → B → C)
nodeA.next ← nodeB
nodeB.next ← nodeC
nodeC.next ← null
// 挿入処理
nodeX.next ← nodeB.next
nodeB.next ← nodeX

第1問 解答と解説

正解： エ (99)

ポインタがどのように繋ぎ変えられたかを順番にトレースします。

  1. 初期状態： nodeA(10) → nodeB(20) → nodeC(30) → null
  2. nodeX.next ← nodeB.next：
    nodeBの次（C）を、新しいノードXの次として設定します。
    これにより、Xの右腕がCに繋がります。
    (状態) X(99) → C(30)
  3. nodeB.next ← nodeX：
    nodeBの次を、ノードXに向け直します。
    (状態) B(20) → X(99)

結果として、リスト全体の繋がりは A(10) → B(20) → X(99) → C(30) → null となります。ノードXはBとCの間に割り込みました。

問題で問われている nodeA.next.next.val をたどると：
① nodeA.next は nodeB
② nodeB.next は nodeX
③ nodeX.val は 99
したがって、答えは 99 です。

第2問（発展トレース：ループによる削除）

以下のプログラムは、単方向リストから特定の条件に合うノードを削除（スキップ）するものである。初期状態のリストが 15 → 20 → 25 → 30 → 35 → null であり、先頭ノード（15）が変数 head に格納されているとき、プログラム実行後のリストの並び順として正しいものはどれか。

〇ノード型: curr
curr ← head
while (curr.next != null)
if (curr.next.val が 2 で割り切れる)
// 削除（スキップ）処理
curr.next ← curr.next.next
else
// 次のノードへ進む
curr ← curr.next
endif
endwhile

第2問 解答と解説

正解： イ (15 → 25 → 35 → null)

このプログラムは「次のノードの値が偶数であれば、そのノードをスキップ（削除）する」という処理をリストの最後まで繰り返します。ポインタの動きをトレースします。

現在地(curr) 判定(curr.next.val) 実行される処理 リストの状態
15 20 (偶数) curr.next ← curr.next.next
※15の次を25に向ける		 15 → 25 → 30 → 35
15 ※移動なし 25 (奇数) curr ← curr.next
※currを25に進める		 15 → 25 → 30 → 35
25 30 (偶数) curr.next ← curr.next.next
※25の次を35に向ける		 15 → 25 → 35
25 ※移動なし 35 (奇数) curr ← curr.next
※currを35に進める		 15 → 25 → 35
35 null whileループ終了 15 → 25 → 35 → null

削除（スキップ）を行った直後は、curr を進めないことがポイントです。これにより連続して偶数が来た場合でも見落とすことなく削除できます。最終的に偶数（20, 30）がリストから消え、15 → 25 → 35 → null となります。

第3問（本番レベル・双方向リストへの挿入）

各ノードが next（次ポインタ）と prev（前ポインタ）を持つ双方向リストにおいて、ノードAの直後に新しいノードXを挿入するプログラムである。プログラム中の空欄 [　a　] に入れるべき適切な式はどれか。

※挿入前は、ノードAの直後にノードBが存在している（A ⇄ B）ものとする。

関数 insertDoubly(ノード型: nodeA, ノード型: nodeX)
// ① ノードXのポインタを設定する
nodeX.prev ← nodeA
nodeX.next ← nodeA.next
// ② ノードAの後続ノード（B）が存在すれば、その prev を更新する
if (nodeX.next != null)
    [　a　] ← nodeX
endif

// ③ ノードAの next を更新する
nodeA.next ← nodeX

関数おわり

第3問 解答と解説

正解： ウ (nodeX.next.prev)

双方向リストにノードを割り込ませる場合、合計で4本の矢印（Xのnext/prev、Aのnext、Bのprev）を繋ぎ変える必要があります。代入の順番に細心の注意が必要です。

初期状態： A ⇄ B
ここからノードXを間に挟み、最終的に A ⇄ X ⇄ B にします。

  1. nodeX.prev ← nodeA
    Xの左腕をAに繋ぎます。（A ← X）
  2. nodeX.next ← nodeA.next
    Aの次（つまりB）を、Xの右腕に繋ぎます。（X → B）
    ※この時点で nodeX.next は「ノードB」を指しています。
  3. [　a　] ← nodeX
    次に、Bの左腕（prev）をXに向け返す必要があります。現在、プログラム上で「ノードB」を指し示している変数は nodeA.next または nodeX.next です。
    したがって、Bのprevを書き換えるには nodeX.next.prev（または nodeA.next.prev）と記述し、それに X を代入します。
  4. nodeA.next ← nodeX
    最後に、Aの右腕（next）をXに繋ぎます。（A → X）
    ※これを先に実行してしまうと、Bの場所（nodeA.next）が迷子になってしまうため、必ず最後に実行します。

よって、空欄には nodeX.next.prev が入ります。
