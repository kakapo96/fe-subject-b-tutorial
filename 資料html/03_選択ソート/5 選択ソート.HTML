科目B対策：選択ソートの仕組みと擬似言語

テーマ：一番背の低い人を探して前に立たせる（選択ソート）

今回もバラバラの5つの数字を「小さい順（昇順）」に並べ替えます。
最初の配列： [5, 3, 4, 1, 2]

選択ソートのたった1つのルール

「まだ並んでいない範囲の中から『一番小さい数（最小値）』を探し出し、その範囲の先頭の人と場所をチェンジする」

動きのシミュレーション

【1周目】 探す範囲：1番目〜5番目

  • 現在の配列： [5, 3, 4, 1, 2] （先頭は5）
  • この範囲で「一番小さい数」を探す → 4番目の 1 だ！
  • 先頭の 5 と、見つけた 1 をチェンジ！
  • 結果： [1 | 3, 4, 5, 2]
    （これで1番目の 1 は場所が確定！次は2番目以降を見ます）

【2周目】 探す範囲：2番目〜5番目

  • 現在の配列： [1 | 3, 4, 5, 2] （未確定の先頭は3）
  • 2番目以降で「一番小さい数」を探す → 5番目の 2 だ！
  • 先頭の 3 と、見つけた 2 をチェンジ！
  • 結果： [1, 2 | 4, 5, 3]

【3周目】 探す範囲：3番目〜5番目

  • 現在の配列： [1, 2 | 4, 5, 3] （未確定の先頭は4）
  • 3番目以降で「一番小さい数」を探す → 5番目の 3 だ！
  • 先頭の 4 と、見つけた 3 をチェンジ！
  • 結果： [1, 2, 3 | 5, 4]

【4周目】 探す範囲：4番目〜5番目

  • 現在の配列： [1, 2, 3 | 5, 4] （未確定の先頭は5）
  • 4番目以降で一番小さい数を探す → 5番目の 4 だ！
  • 先頭の 5 と 4 をチェンジ！
  • 結果： [1, 2, 3, 4 | 5]
    これで5番目（最後）も自動的に確定し、完全に並び替わりました！

本番形式：選択ソートの擬似言語

  • 配列 data には、バラバラの数字が入っているとします。
  • 配列の要素番号（インデックス）は 1 から始まります。
〇整数型の配列: data
〇整数型: i, j, tmp
〇整数型: minIdx  // 一番小さい数が入っている「場所（インデックス）」をメモする箱
〇整数型: N

N ← dataの要素数  // 例：データが5個なら N=5

// 【外側のループ】 確定させる場所を左から順番に進めていく
for (i を 1 から N - 1 まで 1 ずつ増やす)
    
    // とりあえず、今の先頭（i番目）が一番小さいと仮定して場所をメモする
    minIdx ← i
    
    // 【内側のループ】 仮定した数より「もっと小さい数」がないか探す！
    // (i + 1)番目から最後までを探しに行く
    for (j を i + 1 から N まで 1 ずつ増やす)
        
        // もし、いま記録している最小値より小さい数を見つけたら…
        if (data[j] < data[minIdx])
            minIdx ← j   // 「一番小さい数の場所」のメモを書き換える！
        endif
    endfor
    
    // 探し終わったら、未確定エリアの先頭(i)と、見つけた最小値(minIdx)をチェンジ！
    tmp ← data[i]
    data[i] ← data[minIdx]
    data[minIdx] ← tmp

endfor

本番の試験で「穴埋め」にされるポイント

試験では、このプログラムのどこかが「空欄（ [　a　] など）」になっていて、そこに入る式を選ばせる問題がよく出ます。
特に狙われるのは、以下の3箇所です。バブルソートとの違いを意識して確認しましょう。

狙われるポイント①：内側のループのスタート地点

空欄の例
for (j を [　a　] から N まで 1 ずつ増やす)
正解
i + 1
なぜ？
外側のループ i は「いま確定させようとしている場所（未確定エリアの先頭）」です。一番小さい数を探す旅は、その場所自身をもう一度見る必要はなく、「その1つ右の場所（i + 1）」から最後までを探しに行けばよいからです。

狙われるポイント②：最小値を更新する条件

空欄の例
if (data[j] < [　b　])
正解
data[minIdx]
なぜ？
「今見ている数（data[j]）」が、「今までで一番小さいと思っていた数（data[minIdx]）」よりも小さかったら、新記録更新です。このとき、場所のメモである minIdx を、見つけた新しい場所 j に書き換えます。

狙われるポイント③：入れ替え（スワップ）の対象

空欄の例
tmp ← data[i]
data[i] ← [　c　]
[　c　] ← tmp
正解
data[minIdx]
なぜ？
バブルソートは「隣同士（j と j+1）」を入れ替えていましたが、選択ソートは「未確定エリアの先頭（i）と、探し出した一番小さい数の場所（minIdx）」をドカンと一発で入れ替えます。
tmp ← data[i]
data[i] ← data[minIdx]
data[minIdx] ← tmp

【試験で1秒で見抜くコツ】
内側のループにある if 文が「場所のメモの更新だけ」で、入れ替え（3行セット）を内側ループが「終わった後」に1回だけやっていたら、それは「選択ソート」です！
