【科目B対策】文法ルール：再帰関数（再帰呼び出し）

再帰（さいき）とは、「プログラム（関数）の中で、自分自身の関数をもう一度呼び出す」という特殊な書き方です。
クイックソートやマージソート、木構造の走査など、少し複雑なアルゴリズムはほぼ全てこの「再帰」を使って書かれています。

テーマ：マトリョーシカを開け進め、最後に閉じていく

今回は例として、「1からNまでを順番に足し算する関数（N = 5のとき）」をシミュレーションしてみます。
※本来はループで書けますが、あえて再帰で表現するとどうなるかを見てみましょう。

再帰関数のたった2つの絶対ルール

  • ① 終了条件（ストッパー）： これ以上自分を呼び出さない、一番奥底の条件が絶対に必要。（例：Nが1になったら終わり）
  • ② 漸化式（ぜんかしき）： 自分自身を呼び出すときは、必ずゴール（ストッパー）に近づくように引数を変化させる。（例：N-1 を渡す）

動きのシミュレーション： f(5) を計算する！

【行き（ドンドンもぐる）】

関数は「自分の仕事の一部」を、少し小さくした自分自身に丸投げしていきます。この時点ではまだ答えは出ません（待機状態）。

f(5) ＝ 5 ＋ f(4)
    f(4) ＝ 4 ＋ f(3)
        f(3) ＝ 3 ＋ f(2)
            f(2) ＝ 2 ＋ f(1)

【ストッパー発動！】

引数がついに「1」になりました。ここで初めて「f(1) は 1 を返す」という具体的な答えが出ます。

                f(1) ＝ 1

【帰り（巻き戻して計算する）】

一番奥から具体的な数字が返ってきたので、待機していた計算が一気にドミノ倒しのように解けていきます！

            f(2) ＝ 2 ＋ 1 ＝ 3
        f(3) ＝ 3 ＋ 3 ＝ 6
    f(4) ＝ 4 ＋ 6 ＝ 10
f(5) ＝ 5 ＋ 10 ＝ 15

最終的に一番初めに呼び出した f(5) の答えが 15 だと分かりました！

本番形式：再帰関数の擬似言語

試験では、先ほどの「1からNまでの和を求める計算」が、以下のような非常に短いプログラムとして出題されます。

// Nまでの和を計算する関数 sum を定義
関数 sum(整数型: N) 戻り値: 整数型
    
    // ① 【終了条件（ストッパー）】
    // Nが1以下のときは、もう計算せずにそのまま「1」を返す
    if (N <= 1)
        return 1
    endif
    
    // ② 【再帰呼び出し】
    // 今の数字(N) に、「1つ小さい数字(N-1)までの和」を足したものを返す
    return N + sum(N - 1)
    
関数おわり

// ---------------------------------------
// 【メイン処理での呼び出し方】
〇整数型: result
result ← sum(5)  // ここからマトリョーシカが始まる！
// result には 15 が入る

本番の試験で「穴埋め」にされるポイント

再帰関数のプログラム問題で問われる空欄は、ほぼ100％以下の2つのどちらかです。

狙われるポイント①：終了条件（ストッパー）

空欄の例
if ([　a　])
    return 1
正解
N <= 1
なぜ？
もしこのストッパーがなかったら、sum(0)、sum(-1)、sum(-2)...と永遠に呼び出し続けてしまい、プログラムがフリーズしてしまいます（無限ループ、スタックオーバーフロー）。どこで呼び出しを止めるべきかを考えましょう。

狙われるポイント②：自分自身を呼び出すときの「引数」

空欄の例
return N + sum( [　b　] )
正解
N - 1
なぜ？
再帰呼び出しをする時は、「必ずストッパー（今回は1）に向かって進むように、引数を変化させる」必要があります。もしここで sum(N) や sum(N + 1) を渡してしまうと、永遠にストッパーの「1」に辿り着けません。

【試験で再帰関数が出た時の解き方】
プログラムを頭の中だけで処理しようとすると必ず混乱します。
余白に f(3) = 3 + f(2)、f(2) = 2 + f(1) といったように、「一番小さな数字（ストッパー）」にたどり着くまでメモを書き出し、下から上に逆算して足し上げていく（代入していく）のが確実で最速の解き方です！
