【科目B対策】データ構造：スタック

データ構造とは、データをメモリ上に「どうやって並べて保存するか」のルールのことです。
試験でよく出る「スタック」は、「机の上に積んだ本」に例えると一瞬で理解できます。

テーマ①：机の上に積んだ本（スタック / Stack）

机の上に本を1冊ずつ積み上げていきます。下にある本を取り出したい時は、上にある本を先にどかさないといけません。

スタックのルール：LIFO（Last In, First Out / 後入れ先出し）

「最後に入れたデータが、最初に取り出される」
・入れる操作を Push（プッシュ） と呼ぶ。
・出す操作を Pop（ポップ） と呼ぶ。
・現在どこまで積み上がっているかを示す指差し棒を スタックポインタ（SP） と呼ぶ。

【動きのシミュレーション】 空箱にデータを入れる

  • 初期状態（空っぽ）： [ , , , ] （SPは0）
  • Push(10)： [10, , , ] （SPが1になり、1番目に10を入れる）
  • Push(20)： [10, 20, , ] （SPが2になり、2番目に20を入れる）
  • Push(30)： [10, 20, 30, ] （SPが3になり、3番目に30を入れる）
  • Pop() を実行！： 一番上の 30 が取り出される。
    結果： [10, 20, , ] に戻り、SPは2に減る。

本番形式：配列を使ったスタックの実装

試験の科目Bでは、「普通の配列」と「ポインタ変数（SP）」を使って、スタックの動きをプログラミングで再現する問題が出ます。

// グローバル変数の準備
〇整数型の配列: stack    // データを保存する配列
〇整数型: sp             // スタックポインタ（現在データが何個入っているか）

// 初期化
sp ← 0                   // 最初は空っぽなので0

// データを【入れる】関数
関数 push(整数型: val)
    // まずポインタを「1」増やして、新しい空き部屋を指す
    sp ← sp + 1
    // その部屋にデータを置く
    stack[sp] ← val
関数おわり

// データを【出す】関数
関数 pop() 戻り値: 整数型
    〇整数型: ret
    // 今ポインタが指している一番上のデータを退避する
    ret ← stack[sp]
    // ポインタを「1」減らして、一つ下の部屋を指すようにする
    sp ← sp - 1
    return ret           // 取り出したデータを返す
関数おわり

本番の試験で「穴埋め」にされるポイント

試験では、スタックポインタ（sp）を「いつ増やすか？いつ減らすか？どう移動するか？」が必ず問われます。

狙われるポイント①：スタックに値を入れる（Push）とき

空欄の例
[ a ] ← sp + 1
stack[sp] ← val
正解
sp
なぜ？
新しい本を積むときは、まず「今の高さ（sp）」を1段上にあげてから、その場所に本（val）を置く必要があるからです。

狙われるポイント②：スタックから値を出す（Pop）とき

空欄の例
ret ← stack[sp]
[ b ]
正解
sp ← sp - 1
なぜ？
一番上の本（ret）を取り出したら、山の高さが1段低くなります。そのため、スタックポインタ（sp）を1減らして、一つ下を指すように更新しなければなりません。

【暗記ポイント】
スタック ＝ LIFO（後入れ先出し）＝ ブラウザの「戻る」ボタンや、関数の呼び出し。
