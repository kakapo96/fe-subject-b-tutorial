【科目B対策】データ構造：キュー

データ構造とは、データをメモリ上に「どうやって並べて保存するか」のルールのことです。
試験でよく出る「キュー」は、「レジの順番待ち」に例えると一瞬で理解できます。

テーマ：レジの順番待ち（キュー / Queue）

スーパーのレジの順番待ち（行列）です。先に並んだ人から順番にお会計をしてもらえます。横入りは禁止です。

キューのルール：FIFO（First In, First Out / 先入れ先出し）

「最初に入れたデータが、最初に取り出される」
・入れる操作を Enqueue（エンキュー） と呼ぶ。
・出す操作を Dequeue（デキュー） と呼ぶ。
・「先頭」と「末尾」の2つの指差し棒（Head と Tail）を使うのが特徴。

【動きのシミュレーション】 トンネルを通り抜ける

  • 初期状態（空っぽ）： [ , , , ]
  • Enqueue(10)： [10, , , ] （末尾[Tail]から入る）
  • Enqueue(20)： [10, 20, , ] （後ろに並ぶ）
  • Enqueue(30)： [10, 20, 30, ] （さらに後ろに並ぶ）
  • Dequeue() を実行！： 一番先頭（Head）の 10 が呼ばれて出ていく。
    結果： [ , 20, 30, ] （先頭[Head]が一つ後ろにズレる）

本番形式：配列を使ったキューの実装（リングバッファ）

キューもスタックと同様に配列とポインタを使って実装します。要素が右端に到達したら左端（1番目）に戻る「リングバッファ」の仕組みを取り入れた頻出コードです。

// グローバル変数の準備
〇整数型の配列: queue    // データを保存する配列
〇整数型: head           // 先頭を指すポインタ（出す場所）
〇整数型: tail           // 末尾を指すポインタ（次に入れる場所）
〇整数型: max_len        // 配列の長さ（定員）

// 初期化（1番目スタート）
head ← 1
tail ← 1
max_len ← queueの要素数

// データを【入れる】関数（エンキュー）
関数 enqueue(整数型: val)
    // 現在のtail（末尾）の場所にデータを置く
    queue[tail] ← val
    // tailを1つ進める。右端に着いたら「1」に戻る！
    tail ← (tail % max_len) + 1
関数おわり

// データを【出す】関数（デキュー）
関数 dequeue() 戻り値: 整数型
    〇整数型: ret
    // 現在のhead（先頭）のデータを取り出す
    ret ← queue[head]
    // headを1つ進める。右端に着いたら1に戻る
    head ← (head % max_len) + 1
    return ret
関数おわり

本番の試験で「穴埋め」にされるポイント

試験では、キューのポインタ（head, tail）を「いつ増やすか？いつ減らすか？どう移動するか？」が必ず問われます。

🔥 狙われるポイント：キューのポインタ移動（リングバッファ）

空欄の例
tail ← [ a ]
正解
(tail % max_len) + 1
なぜ？
配列の右端（限界）に到達したとき、エラーにならずに左端（1番目）へぐるっと戻るための魔法の式です。割り算の余り（% または mod）を使うことで、tail や head は常に 1 から配列の長さまでの範囲をループし続けます。科目Bで頻出のテクニックです。

【暗記ポイント】
キュー ＝ FIFO（先入れ先出し）＝ プリンタの印刷待ちや、レジの順番待ち。
