第1問（基礎トレース・木の走査）

以下のような構成を持つ2分木がある。

  • 根（ルート）ノードの値： 50
  • 50の左の子の値： 30
  • 50の右の子の値： 70
  • 30の左の子の値： 10
  • （これ以外のノードは存在しない）

この木に対して、根ノードを引数として以下の関数 traverse を実行したとき、出力される数値の順番として正しいものはどれか。

関数 traverse(ノード型: node)
    if (node == null)
        return
    endif
    
    print(node.val)
    traverse(node.left)
    traverse(node.right)
関数おわり

第1問 解答と解説

正解： イ (50, 30, 10, 70)

このプログラムは「先行順（前順 / 行きがけ順）」で木を走査する処理です。「ノードに初めて着いた瞬間に読む（出力する）」というルールで動きます。

関数のトレースは以下のようになります：

  • 1. traverse(50のノード) が呼ばれる。
  • 2. まず自分自身を出力する。 → 【出力: 50】
  • 3. 左の子（30のノード）へ進み、traverse(30のノード) を呼び出す。
  • 4. 自分自身を出力する。 → 【出力: 30】
  • 5. 左の子（10のノード）へ進み、traverse(10のノード) を呼び出す。
  • 6. 自分自身を出力する。 → 【出力: 10】
  • 7. 10のノードには子がない（null）ため引き返し、30のノードの右の子を確認するが、これも無い（null）ためさらに引き返す。
  • 8. 50のノードに戻り、今度は右の子（70のノード）へ進み、traverse(70のノード) を呼び出す。
  • 9. 自分自身を出力する。 → 【出力: 70】

よって、出力される順番は 50 → 30 → 10 → 70 となります。

第2問（発展トレース・2分探索木の探索）

「左の子孫はすべて親より小さく、右の子孫はすべて親より大きい」というルールを持つ2分探索木がある。この木は以下の構成となっている。

  • 根（ルート）： 50
  • 50の左： 30、 50の右： 80
  • 80の左： 60、 80の右： 90
  • 60の右： 65

この木から目的の値 target を探す以下の関数を実行し、search(根ノード, 65) を呼び出した場合、node.val として比較される値の推移（順番）として正しいものはどれか。

関数 search(ノード型: node, 整数型: target)
    if (node == null)
        return "見つかりません"
    endif
    
    if (node.val == target)
        return "見つかりました"
    endif
    
    if (node.val > target)
        // ターゲットの方が小さい場合は左へ
        return search(node.left, target)
    else
        // ターゲットの方が大きい場合は右へ
        return search(node.right, target)
    endif
関数おわり

第2問 解答と解説

正解： ウ (50 → 80 → 60 → 65)

2分探索木の「左 ＜ 親 ＜ 右」という性質を利用した探索（2分探索と同じ原理）のトレースです。target は 65 です。

トレースの推移：

  • 1回目： 現在の node.val は根の 50。
    50 > 65 は偽（ターゲットの方が大きい）なので、else に入り右の子へ進む。
  • 2回目： 現在の node.val は 80。
    80 > 65 は真（ターゲットの方が小さい）なので、左の子へ進む。
  • 3回目： 現在の node.val は 60。
    60 > 65 は偽（ターゲットの方が大きい）なので、else に入り右の子へ進む。
  • 4回目： 現在の node.val は 65。
    node.val == target (65 == 65) となるため、"見つかりました" を返して終了する。

したがって、比較されたノードの値の順番は 50 → 80 → 60 → 65 となります。

第3問（本番レベル・穴埋め）

2分探索木に格納されたすべてのデータを、昇順（小さい順）に出力するプログラムを作成したい。

空欄 [ a ] に入る最も適切な処理はどれか。

関数 traverse_asc(ノード型: node)
    if (node == null)
        return
    endif
    
    traverse_asc(node.left)
    
    [       a       ]
    
    traverse_asc(node.right)
関数おわり

第3問 解答と解説

正解： ウ (print(node.val))

この問題は「中間順（間順 / 通りがけ順 / In-order）」の性質を問う、試験での最頻出ポイントです。

2分探索木は「左の子孫 ＜ 自分 ＜ 右の子孫」というルールで並んでいます。そのため、データを小さい順（昇順）に取り出したい場合は、以下の順序で処理を行う必要があります。

  • 1. traverse_asc(node.left) : まず、自分より小さいデータが集まっている「左の道」をすべて処理する。
  • 2. print(node.val) : 左の処理が全て終わったタイミング（中間）で、自分自身を出力する。
  • 3. traverse_asc(node.right) : 最後に、自分より大きいデータが集まっている「右の道」を処理する。

他の選択肢の誤り理由：

  • ア・イ： 再帰関数の中でさらに `.left.val` や `.right.val` を直接出力しようとすると、葉ノード（子がないノード）でエラーになります。
  • エ： traverse_asc は「ノード型」を引数に取る関数ですが、node.val（数値）を渡しているため型エラーになります。
  • オ： return してしまうと、右の子の処理 traverse_asc(node.right) に進む前に関数が終了してしまいます。
