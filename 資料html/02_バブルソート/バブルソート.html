第1問（基礎トレース）

以下のバブルソート（昇順）のプログラムを実行します。 初期状態の配列 data が [5, 3, 4, 1, 2] であるとき、外側のループ（変数 i のループ）が1周目（i = 1）を完了した直後の配列 data の中身として正しいものはどれか。 ※配列の要素番号（インデックス）は1から始まるとする。

〇整数型の配列: data ← {5, 3, 4, 1, 2}
〇整数型: i, j, tmp
〇整数型: N ← 5
for (i を 1 から N - 1 まで 1 ずつ増やす)
for (j を 1 から N - i まで 1 ずつ増やす)
if (data[j] > data[j+1])
tmp ← data[j]
data[j] ← data[j+1]
data[j+1] ← tmp
endif
endfor
endfor

第1問 解答と解説

正解： エ: [3, 4, 1, 2, 5]

バブルソートの1周目（i = 1）の動きを順番にトレースします。
内側のループ（j）は 1 から 4（N - i = 5 - 1）まで動きます。

  • 初期状態： [5, 3, 4, 1, 2]
  • j=1のとき： data[1]の「5」とdata[2]の「3」を比較。 5 > 3 が成立するので入れ替え。
    → [3, 5, 4, 1, 2]
  • j=2のとき： data[2]の「5」とdata[3]の「4」を比較。 5 > 4 が成立するので入れ替え。
    → [3, 4, 5, 1, 2]
  • j=3のとき： data[3]の「5」とdata[4]の「1」を比較。 5 > 1 が成立するので入れ替え。
    → [3, 4, 1, 5, 2]
  • j=4のとき： data[4]の「5」とdata[5]の「2」を比較。 5 > 2 が成立するので入れ替え。
    → [3, 4, 1, 2, 5]

これで1周目（i=1）が終了し、配列の中で最も大きい「5」が右端に確定しました。

第2問（発展トレース）

第1問と同じプログラムを引き続き実行します。
外側のループの2周目（i = 2）が終了した直後において、配列の3番目の要素（data[3]）の値はいくつになっていますか。

// ※第1問終了時（i=1完了時点）の配列状態
// data = [3, 4, 1, 2, 5]
// ここから i = 2 の処理がスタートします。

第2問 解答と解説

正解： イ: 2

2周目（i = 2）の動きをトレースします。
1周目終了時点の配列は [3, 4, 1, 2, 5] です。内側のループ（j）は 1 から 3（N - i = 5 - 2）まで動きます。

  • 開始時： [3, 4, 1, 2, 5]
  • j=1のとき： data[1](3) と data[2](4) を比較。 3 > 4 は「偽」なのでそのまま。
    → [3, 4, 1, 2, 5]
  • j=2のとき： data[2](4) と data[3](1) を比較。 4 > 1 は「真」なので入れ替え。
    → [3, 1, 4, 2, 5]
  • j=3のとき： data[3](4) と data[4](2) を比較。 4 > 2 は「真」なので入れ替え。
    → [3, 1, 2, 4, 5]

これで j=3 まで完了したため、2周目（i=2）が終了します。
この時点での配列は [3, 1, 2, 4, 5] となり、インデックス1から数えて3番目の要素 data[3] は 2 となります。

第3問（本番レベル・穴埋め）

今度は、配列 data の要素を「大きい順（降順）」に並べ替えるバブルソートのプログラムを作成します。
以下の擬似言語の空欄 [ a ] と [ b ] に入る字句の組み合わせとして、最も適切なものはどれか。

〇整数型の配列: data
〇整数型: i, j, tmp
〇整数型: N ← dataの要素数
for (i を 1 から N - 1 まで 1 ずつ増やす)
for (j を 1 から [  a  ] まで 1 ずつ増やす)
if (data[j] [  b  ] data[j+1])
tmp ← data[j]
data[j] ← data[j+1]
data[j+1] ← tmp
endif
endfor
endfor

第3問 解答と解説

正解： ウ: [ a ] N - i    / [ b ] <

それぞれの空欄に入る理由を解説します。

  • [ a ] 内側のループの終了条件：
    バブルソートでは、外側のループ（i）が1周終わるごとに、右端から順番に値が確定していきます（泡が浮かび上がるように場所が決まる）。確定した右側の要素はもう比較する必要がないため、内側のループは N - i までで止めるのが最も効率的です。（空欄a = N - i）
  • [ b ] if文の比較条件：
    今回は「大きい順（降順）」に並べ替えます。つまり、左側の要素が右側の要素より小さかったら、「順番が間違っている」として入れ替える必要があります。
    したがって、条件式は「もし左（data[j]）が右（data[j+1]）より小さければ」となり、不等号は < となります。（空欄b = <）
