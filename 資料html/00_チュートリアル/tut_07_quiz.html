解き放て、Stage 1の扉！最終確認テスト

要素が1から始まる整数型の配列 data に {10, 20, 30} が格納されています。
手元の白紙にしっかりと変数を書き出し、以下のプログラムを実行し終えたとき、最終的な変数 i の値はどうなるか答えなさい。

〇整数型の配列: data ← {10, 20, 30}
〇整数型: i

i ← 1
while (i <= dataの要素数)
    i ← i + 1
endwhile

テスト 結果発表

🎉 正解： ウ (4)

whileループの「境界値（ストッパー）」の動きを正確に見抜けたでしょうか？
dataの要素数 は 3 です。したがって条件式は while (i <= 3) となります。
紙の上での変数の変化を追ってみましょう。

初期状態： i = 1

1周目判定： 1 <= 3 ➔ 真 (True) ➔ ループに入る
  i ← 1 + 1 = 2 に上書き

2周目判定： 2 <= 3 ➔ 真 (True) ➔ ループに入る
  i ← 2 + 1 = 3 に上書き

3周目判定： 3 <= 3 ➔ 真 (True) ➔ ループに入る （※「以下」なので3のときも入る！）
  i ← 3 + 1 = 4 に上書き

4周目判定： 4 <= 3 ➔ 偽 (False) ❌ ➔ ループ終了！中に入らず脱出！

ループを完全に抜け出したときの、変数 i の最新の数字は 4 になっています！
「要素数が3個だから3で止まるだろう」という思い込み（暗記脳）を完全に撃破し、条件式に最新の数値を愚直に当てはめてブレーキをかける「純粋なトレース力」こそが、科目Bを完全攻略するための最強の武器です！
