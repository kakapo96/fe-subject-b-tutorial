07 チュートリアル最終確認テスト

ここまで本当にお疲れ様でした！
科目B（アルゴリズム）の初学者が必ずつまずく重要基礎ポイントのトレースを、一緒に5つもクリアしてきました。

💡 これまで学んだ「科目Bの5大鉄則」

  • 変数の上書き：代入された瞬間に古い数字は消える。直前の行で作られた最新の数字を使うこと。
  • 関数のネスト：一番奥底の関数から順番に処理が完了し、戻り値を持って逆戻りする。
  • 条件分岐の順序：if文は上から順番に判定される。条件は「厳しい順」に並べる。
  • whileループの境界：ループが継続するか止まるかは、最新の数字を条件式に当てはめて判定する。
  • 配列の1始まり：配列は「1番目」からスタート！全要素をループで回す終了条件は「以下(<=)」。

最後のトレース問題に挑戦！

要素が1から始まる整数型の配列 data に {10, 20, 30} が格納されています。
手元の白紙にしっかりと変数を書き出し、以下のプログラムを実行し終えたとき、最終的な変数 i の値はどうなるか答えなさい。

〇整数型の配列: data ← {10, 20, 30}
〇整数型: i

i ← 1
while (i <= dataの要素数)
    i ← i + 1
endwhile

🎉 正解： ウ (4)

whileループの「境界値（ストッパー）」の動きを正確に見抜けたでしょうか？
dataの要素数 は 3 です。したがって条件式は while (i <= 3) となります。

初期状態： i = 1

1周目判定： 1 <= 3 ➔ 真 (True) ➔ ループに入る
  i ← 1 + 1 = 2 に上書き

2周目判定： 2 <= 3 ➔ 真 (True) ➔ ループに入る
  i ← 2 + 1 = 3 に上書き

3周目判定： 3 <= 3 ➔ 真 (True) ➔ ループに入る （※「以下」なので3のときも入る！）
  i ← 3 + 1 = 4 に上書き

4周目判定： 4 <= 3 ➔ 偽 (False) ❌ ➔ ループ終了！

ループを完全に抜け出したときの最新の数字は 4 になっています！
