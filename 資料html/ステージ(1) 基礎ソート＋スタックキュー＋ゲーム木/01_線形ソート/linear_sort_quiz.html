第1問（基礎トレース）

要素が1から始まる整数型の配列 data に [22, 14, 50, 39, 61] が格納されています。
以下のプログラムを実行したとき、最終的な変数 ans の値はどうなるか。

〇整数型の配列: data ← {22, 14, 50, 39, 61}
〇整数型: target ← 39
〇整数型: ans, i

ans ← -1
for (i を 1 から dataの要素数 まで 1 ずつ増やす)
    if (data[i] == target)
        ans ← i
        break
    endif
endfor

第1問 解答と解説

正解： エ (4)

線形探索法の基本的なトレース問題です。配列の先頭（1番目）から順番に target (39) と比較を行います。

  • 初期状態: ans = -1
  • 1周目 (i=1): data[1]は22。39と一致しないため次へ。
  • 2周目 (i=2): data[2]は14。39と一致しないため次へ。
  • 3周目 (i=3): data[3]は50。39と一致しないため次へ。
  • 4周目 (i=4): data[4]は39。target(39)と一致した！

一致したため ans ← i (ans に 4 を代入) が実行され、break によりループを終了します。したがって、最終的な ans の値は 4 となります。

第2問（発展トレース）

要素が1から始まる整数型の配列 data に [8, 12, 19, 21] が格納されています。
以下のプログラムを実行したとき、最終的な変数 ans の値はどうなるか。

〇整数型の配列: data ← {8, 12, 19, 21}
〇整数型: target ← 15
〇整数型: ans, i

ans ← -1
for (i を 1 から dataの要素数 まで 1 ずつ増やす)
    if (data[i] == target)
        ans ← i
        break
    endif
endfor

第2問 解答と解説

正解： ア (-1)

配列の中に探している値が存在しない場合のトレース問題です。探している値 target は 15 です。

  • 初期状態: ans = -1, 配列の要素数は 4
  • 1周目 (i=1): data[1]は8。15と一致しない。
  • 2周目 (i=2): data[2]は12。15と一致しない。
  • 3周目 (i=3): data[3]は19。15と一致しない。
  • 4周目 (i=4): data[4]は21。15と一致しない。

ループが 1 から 4 まで全て回り切りましたが、一度も if (data[i] == target) の条件が「真」になりませんでした。
そのため、ループ内の ans ← i は一度も実行されず、ans の値は初期値の -1 のままとなります。

第3問（本番レベル・穴埋め）

以下のプログラムは、線形探索を高速化するための「番兵法」を用いた探索アルゴリズムです。
要素数 N の配列 data（インデックスは1〜N）の末尾に番兵を追加して探索を行います。
空欄 [ a ] および [ b ] に入る式の組み合わせとして正しいものはどれか。

〇整数型の配列: data // 1番目からN番目までデータが入っている
〇整数型: N, target
〇整数型: i, ans

// 番兵を配列の最後にセットする
data[ [  a  ] ] ← target

i ← 1
// 配列の最後まで来たかのチェックが不要になる
while (data[i] ≠ target)
    i ← i + 1
endwhile

// 見つかった場所が番兵だったかどうかを判定
if (i == [  b  ])
    ans ← -1    // 見つからなかった
else
    ans ← i     // 見つかった
endif

第3問 解答と解説

正解： オ ([a] N + 1 , [b] N + 1)

「番兵法」は、配列の最後に探している値（番兵）を強制的に追加することで、ループ時の「配列の末尾に到達したか？」という終了判定を省略し、処理を高速化するアルゴリズムです。

  • 空欄 [ a ] について：
    配列 data には現在 1番目 から N番目 までデータが入っています。番兵を追加する場所は「現在の最後尾の1つ後ろ」なので、N + 1 番目になります。（例: データが5個なら6番目に番兵を置く）
  • 空欄 [ b ] について：
    while ループを抜けたとき、変数 i には「値が見つかったインデックス」が入っています。
    もし i が N + 1 であった場合、それは元々あったデータではなく「自分が追加した番兵を見つけてループが止まった（＝元のデータには存在しなかった）」ことを意味します。
    したがって、i == N + 1 のときに「見つからなかった (ans ← -1)」という処理を行う必要があります。
