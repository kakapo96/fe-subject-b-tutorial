科目B対策：バブルソートの仕組みと擬似言語

テーマ：背の順に並べ替える（バブルソート）

バラバラに並んだ5つの数字を「小さい順（昇順）」に並べ替えます。
最初の配列： [5, 3, 4, 1, 2]

バブルソートのたった1つのルール

「左から順番に『隣同士』を見比べて、左の方が大きければ場所をチェンジ（入れ替え）する」
これをひたすら繰り返すだけです。

動きのシミュレーション

【1周目】 一番大きい数を右端に押しやる

  • 1番目と2番目： [5, 3, 4, 1, 2] → 左が大きいのでチェンジ！
  • 2番目と3番目： [3, 5, 4, 1, 2] → 左が大きいのでチェンジ！
  • 3番目と4番目： [3, 4, 5, 1, 2] → 左が大きいのでチェンジ！
  • 4番目と5番目： [3, 4, 1, 5, 2] → 左が大きいのでチェンジ！
  • 1周目終了： [3, 4, 1, 2 | 5]
    （一番大きかった 5 が右端に浮かび上がり、場所が確定しました！）

【2周目】 二番目に大きい数を右に押しやる

  • 1番目と2番目： [3, 4, 1, 2 | 5] → そのまま（何もしない）
  • 2番目と3番目： [3, 4, 1, 2 | 5] → 左が大きいのでチェンジ！
  • 3番目と4番目： [3, 1, 4, 2 | 5] → 左が大きいのでチェンジ！
  • 2周目終了： [3, 1, 2 | 4, 5]
    （次に大きかった 4 が確定しました。確定した右側はもう見ません。）

【その後（3周目、4周目）】

  • 3周目終了時： [1, 2 | 3, 4, 5] （3が確定）
  • 4周目終了時： [1 | 2, 3, 4, 5] （2が確定し、自動的に1も確定）
  • これで完全に並び替わりました！

本番形式：バブルソートの擬似言語

実際の「科目B（旧午後試験）」で出題される擬似言語のフォーマットに合わせて、プログラムを書き起こしました。
どこで何をしているのか、横に解説（コメント）を添えていますので、プログラムの流れを指でなぞりながら読んでみてください。

  • 配列 data には、バラバラの数字が入っているとします。
  • 配列の要素番号（インデックス）は 1 から始まります。
〇整数型の配列: data
〇整数型: i, j, tmp
〇整数型: N

N ← dataの要素数  // 例：データが5個なら N=5

// 【外側のループ】全体を何周するか（N個ならN-1周で完了する）
for (i を 1 から N - 1 まで 1 ずつ増やす)
    
    // 【内側のループ】隣同士を比べていく
    // (N - i) までなのは、右側に確定した「泡」の部分を再び見ないため
    for (j を 1 から N - i まで 1 ずつ増やす)
        
        // もし左(j)の方が、右(j+1)より大きかったら
        if (data[j] > data[j+1])
            
            // ３ステップで入れ替え（チェンジ）を実行する！
            tmp ← data[j]         // ① 左の数字を tmp(一時避難箱) に移す
            data[j] ← data[j+1]   // ② 空いた左の箱に、右の数字を入れる
            data[j+1] ← tmp       // ③ 右の箱に、避難させておいた数字を入れる
            
        endif
    endfor
endfor

本番の試験で「穴埋め」にされるポイント

試験では、このプログラムのどこかが「空欄（ [　a　] など）」になっていて、そこに入る式を選ばせる問題がよく出ます。
特に狙われるのは、以下の3箇所です。ここだけ理解していれば確実に点が取れます。

狙われるポイント①：内側のループの終わりの条件

空欄の例
for (j を 1 から [　a　] まで 1 ずつ増やす)
正解
N - i
なぜ？
外側のループ（i）が 1周、2周…と進むごとに、右端には一番大きい数字が確定して並んでいきます。確定した右端の数字はもう比べる必要がないため、周回数（i）の分だけ、調べるゴール地点を手前にズラす必要があります。

狙われるポイント②：if文の条件（昇順か降順か）

空欄の例
if (data[j] [　b　] data[j+1])
正解
> （より大きい）
なぜ？
「小さい順（昇順）」に並べたいので、「左が大きかったらダメだから入れ替える」 という条件になります。もし「大きい順（降順）」に並べ替えたい場合は、ここが < に変わります。

狙われるポイント③：入れ替え（スワップ）の式

空欄の例
tmp ← data[j]
data[j] ← [　c　]
data[j+1] ← tmp
正解
data[j+1]
なぜ？
一時避難用の箱（tmp）を使った「玉突き」のような代入です。「右上がり（斜め下）」に同じ変数が並ぶのが特徴です。
tmp ← data[j]
data[j] ← data[j+1]
data[j+1] ← tmp

この形のプログラムを見たら、「あ、外側と内側の二重ループで、中で一時避難箱を使って入れ替えてる！バブルソートだ！」 と瞬時に見抜けるようになります。
