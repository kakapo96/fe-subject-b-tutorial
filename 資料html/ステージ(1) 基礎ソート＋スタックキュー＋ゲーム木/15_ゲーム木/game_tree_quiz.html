🌳 ゲーム木（状態遷移木） 特訓クイズ9番勝負！

「自分は最大値（Max）を選び、相手は最小値（Min）を選ぶ」という基本ルールのもと、3つのパターンの探索手法をマスターしましょう！

第1部：Mini-Max法の基本計算（3問）

末端（葉）の評価値から逆算し、根ノードの評価値を求めてください。

Q1. 基本の2分岐ツリー

自分（Max）の手番から始まります。根ノードの評価値はいくつになりますか？

[根] (自分:Max) / \ [A] [B] (相手:Min) / \ / \ 3 5 2 9
【正解】 3
・相手(Min)Aは、3と5から最小の 3 を選びます。
・相手(Min)Bは、2と9から最小の 2 を選びます。
・自分(Max)根は、Aの3とBの2から最大の 3 を選びます。
Q2. 手が3つある場合（3分岐）

選択肢が3つに増えました。根ノードの評価値はいくつになりますか？

[根] (自分:Max) / | \ [A] [B] [C] (相手:Min) /|\ /|\ /|\ 1 4 2 5 8 7 3 1 6
【正解】 2
・相手A：min(1, 4, 2) = 1
・相手B：min(5, 8, 7) = 5
・相手C：min(3, 1, 6) = 1
・自分根：max(1, 5, 1) = 5 …あれ？解説を作成しているAIが間違えました（笑）。
正解は 5 です！自分は1, 5, 1の中から最も有利な 5 を選びます。
Q3. 少し深い3階層ツリー

もう1階層深くなります。根ノードの評価値はいくつになりますか？

[根] (自分:Max) / \ [A] [B] (相手:Min) / \ / \ [C] [D] [E] [F] (自分:Max) / \ / \ / \ / \ 8 4 7 2 9 1 5 6
【正解】 7
下から計算します。
・自分(Max)層：C=8, D=7, E=9, F=6
・相手(Min)層：A = min(C:8, D:7) = 7
・相手(Min)層：B = min(E:9, F:6) = 6
・自分(Max)根：max(A:7, B:6) = 7

第2部：α-β法による「枝刈り」（3問）

探索を左から順番に行うとき、「この先は探索しても結果に影響しない（無駄）」と判断して省略される葉（末端の値）はどれか答えてください。

Q4. 基本の枝刈り

左から順番に探索します。探索されずに「枝刈り」される葉はどれですか？

[根] (自分:Max) / \ [A] [B] (相手:Min) / \ / \ 4 5 2 9
【正解】 9
1. Aの探索：min(4, 5) = 4。根(Max)は「少なくとも4以上」を確保しました。
2. Bの探索：最初の子「2」を見た瞬間、B(Min)の評価値は「2以下」になることが確定します。
3. 根(Max)は「4」を持っているので、絶対に「2以下」にしかならないBを選ぶことはありません。
4. したがって、Bの残りの子である 9 は探索する必要がなくなり、枝刈りされます。
Q5. 3分岐での枝刈り

少し選択肢が増えました。枝刈り（探索省略）される葉の「数字」をすべて答えてください。

[根] (自分:Max) / | \ [A] [B] [C] (相手:Min) /|\ /|\ /|\ 5 8 9 2 4 6 7 1 3
【正解】 4 と 6 と 1 と 3
1. Aの探索：min(5, 8, 9) = 5。根(Max)の暫定値は 5。
2. Bの探索：最初の子「2」を見た瞬間、Bは「2以下」確定。根の5には勝てないので、残りの 4と6 は枝刈り。
3. Cの探索：最初の子「7」を見る。まだ7なので根の5より大きい。次を見る。
4. Cの2番目の子「1」を見た瞬間、Cは「1以下」確定。根の5には勝てないので、残りの 3 は枝刈り。（※問題の意図として、1を見た瞬間に確定するので、探索しなかったのは3と、Bの4,6となります。失礼しました！正解は 4, 6, 3 です。1自体は「見て判断する」ので探索されています！）
Q6. 相手（Min）からのスタート

今回は根が「相手(Min)」です。枝刈り（探索されずに無視される）となる葉の数字をすべて答えてください。

[根] (相手:Min) / \ [A] [B] (自分:Max) / \ / \ 8 5 9 2
【正解】 2
1. Aの探索：max(8, 5) = 8。根(Min)は「最大でも8以下」を確保しました。
2. Bの探索：最初の子「9」を見た瞬間、B(Max)の評価値は「9以上」になることが確定します。
3. 根(Min)は「8以下」にしたいので、絶対に「9以上」になるBを選ぶことはありません。
4. したがって、Bの残りの子である 2 は探索不要となり、枝刈りされます。

第3部：勝敗の再帰トレース（3問）

FE試験の擬似言語問題に近い形式です。再帰関数の動きを追って勝敗（1=勝ち、0=引分、-1=負け）を判定してください。

Q7. 勝敗ツリーの基礎

自分が勝ちなら 1、引き分けなら 0、負けなら -1 とします。
根ノードの評価値（勝敗）はどうなりますか？

[根] (自分:Max) / \ [A] [B] (相手:Min) / \ / \ 1 -1 0 -1
【正解】 0（引き分け）
・相手Aの選択：1(勝ち)と-1(負け)なら、相手にとって都合の良い -1(自分の負け) を選ぶ。
・相手Bの選択：0(引分)と-1(負け)なら、相手は -1(自分の負け) を選ぶ。
・あれ、両方 -1 ではないですか？ 相手Bの選択を見直します。
相手Bは「自分(Max)の評価」を下げる手を選びます。0と-1なら、当然 -1 を選びます。
ということは、自分(根)は A(-1) と B(-1) のどちらを選んでも -1（負け） になります。
※正解は -1（負け）です！ トレースは正確に！
Q8. 引分への逃げ道

根ノードの評価値（勝敗）はどうなりますか？

[根] (自分:Max) / \ [A] [B] (相手:Min) / \ / \ 1 0 0 -1
【正解】 0（引き分け）
・相手A：1と0なら、自分に不利な 0 を選ぶ。
・相手B：0と-1なら、自分に不利な -1 を選ぶ。
・自分根：Aの0とBの-1なら、最大の 0（引き分け） を選んで負けを回避します。
Q9. 擬似言語プログラムのトレース

以下の手続 playGame に、下の図の根ノードと true を渡したときの戻り値を答えてください。

○整数型：playGame(節：node, 論理型：isMyTurn) if (node が葉である) return node の値 endif if (isMyTurn が true) // 自分の手番 整数型：best ← -99 for (node の全ての子 child について) best ← max(best, playGame(child, false)) endfor return best else // 相手の手番 整数型：best ← 99 for (node の全ての子 child について) best ← min(best, playGame(child, true)) endfor return best endif
[根] (isMyTurn = true) / \ [A] [B] / \ / \ -1 1 -1 0
【正解】 -1
プログラムのロジックは、ここまで手動でやってきた「自分はmax、相手はminを選ぶ」処理と全く同じです。
・Aの処理(isMyTurn=false)：min(-1, 1) = -1
・Bの処理(isMyTurn=false)：min(-1, 0) = -1
・根の処理(isMyTurn=true)：max(-1, -1) = -1
よって戻り値は -1 となります。
