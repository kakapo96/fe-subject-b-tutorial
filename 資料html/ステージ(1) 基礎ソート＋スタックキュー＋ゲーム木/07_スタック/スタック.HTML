第1問（基礎トレース：スタック）

以下のスタック操作を行うプログラムを実行したとき、最終的な変数 sp（スタックポインタ）の値はどうなるか。

// 初期化
〇整数型の配列: stack
〇整数型: sp ← 0

// 操作の実行
push(10)
push(20)
pop()
push(30)
push(40)
pop()

第1問 解答と解説

正解： ウ (2)

スタック（LIFO: 後入れ先出し）のポインタの動きをトレースします。
push で sp は +1 され、pop で sp は -1 されます。

  • 初期状態: sp = 0
  • push(10): sp = 0 + 1 = 1
  • push(20): sp = 1 + 1 = 2
  • pop(): 20が取り出され、sp = 2 - 1 = 1
  • push(30): sp = 1 + 1 = 2
  • push(40): sp = 2 + 1 = 3
  • pop(): 40が取り出され、sp = 3 - 1 = 2

したがって、最終的な sp の値は 2 となります。

第2問（基礎トレース：キュー・リングバッファ）

配列の要素数が4のリングバッファ（キュー）に対して、以下の操作を実行した。すべての操作が完了した時点での、末尾を指すポインタ tail の値はどうなるか。

// 初期化
〇整数型の配列: queue
〇整数型: head ← 1
〇整数型: tail ← 1
〇整数型: max_len ← 4

// 操作の実行
enqueue(10)
enqueue(20)
enqueue(30)
dequeue()
enqueue(40)
enqueue(50)

第2問 解答と解説

正解： イ (2)

キュー（リングバッファ）における tail の動きをトレースします。
enqueue を行うと、tail ← (tail % max_len) + 1 の計算によって更新されます。
dequeue は head を動かしますが、tail の値には影響しません。

  • 初期状態: tail = 1, max_len = 4
  • enqueue(10): tail = (1 % 4) + 1 = 1 + 1 = 2
  • enqueue(20): tail = (2 % 4) + 1 = 2 + 1 = 3
  • enqueue(30): tail = (3 % 4) + 1 = 3 + 1 = 4
  • dequeue(): 先頭データ(10)が出る。headは動くが tailは4のまま。
  • enqueue(40): tail = (4 % 4) + 1 = 0 + 1 = 1 （右端から左端へ戻る！）
  • enqueue(50): tail = (1 % 4) + 1 = 1 + 1 = 2

よって、最終的な tail の値は 2 となります。

第3問（本番レベル・穴埋め：キューの更新）

リングバッファを利用したキューからデータを出す関数（デキュー）において、先頭ポインタ head を正しく更新するための式として、空欄 [　a　] に入る最も適切なものを選べ。

関数 dequeue() 戻り値: 整数型
    〇整数型: ret
    
    // 現在のhead（先頭）のデータを取り出す
    ret ← queue[head]
    
    // headを1つ進める。右端に着いたら1に戻る
    [　a　]
    
    return ret
関数おわり

第3問 解答と解説

正解： ウ ( head ← (head % max_len) + 1 )

配列を使ったリングバッファでは、配列の右端（限界値 max_len）に到達した際に、エラーにならず左端（1番目）に戻る仕組みが必要です。

単純に head ← head + 1（選択肢ア）としてしまうと、配列の限界を超えたときに存在しないメモリ空間を参照してしまいます。
割り算の余り（% または mod）を使うことで、head が max_len に達したとき max_len % max_len = 0 となり、そこに + 1 されることで 1（先頭要素）に戻るループを実現できます。

これは tail を進めるときと全く同じ魔法の式であり、科目Bにおける頻出のテクニックです。
