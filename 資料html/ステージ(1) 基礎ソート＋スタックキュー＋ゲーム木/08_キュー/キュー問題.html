第1問（基礎トレース：FIFOの動き）

キュー（Queue）は「先入れ先出し（FIFO: First In, First Out）」のデータ構造です。データを追加する操作を enqueue、データを取り出す操作を dequeue と呼びます。

初期状態で空のキュー Q に対して、以下の操作を順に行った場合、最後に dequeue(Q) を実行したときに取り出される値はどれでしょうか。

enqueue(Q, 10)
enqueue(Q, 20)
enqueue(Q, 30)
dequeue(Q)
enqueue(Q, 40)
dequeue(Q)

第1問 解答と解説

正解： イ (20)

キューの状態を1行ずつトレースします。左側が「出口（次に取り出されるデータ）」、右側が「入口（新しく追加されるデータ）」とします。

  1. enqueue(Q, 10) → キューの状態： [10]
  2. enqueue(Q, 20) → キューの状態： [10, 20]
  3. enqueue(Q, 30) → キューの状態： [10, 20, 30]
  4. dequeue(Q) → 先に入った 10 が取り出される。キューの状態： [20, 30]
  5. enqueue(Q, 40) → キューの状態： [20, 30, 40]
  6. dequeue(Q) → 次に先頭にいる 20 が取り出される。キューの状態： [30, 40]

したがって、最後の dequeue で取り出される値は 20 です。

第2問（ポインタを用いた配列での実装）

配列 queue を用いてキューを実装します。変数 head はデータを取り出す位置を、変数 tail は次にデータを格納する位置を示します。

初期状態では head = 1, tail = 1 です。
・enqueue は queue[tail] にデータを格納し、tail を 1 増やします。
・dequeue は queue[head] からデータを取り出し、head を 1 増やします。
※今回は配列末尾の折り返し処理（リングバッファ）は考慮しません。

以下の操作を行った直後の、head と tail の値の組み合わせとして正しいものはどれでしょうか。

enqueue(10)
enqueue(20)
enqueue(30)
dequeue()
enqueue(40)

第2問 解答と解説

正解： ウ (head = 2, tail = 5)

各操作における変数の変化をトレースします。

  • 初期状態: head = 1, tail = 1
  • enqueue(10): queue[1] に 10 が入り、tail が 1 増えて 2 になる。
  • enqueue(20): queue[2] に 20 が入り、tail が 1 増えて 3 になる。
  • enqueue(30): queue[3] に 30 が入り、tail が 1 増えて 4 になる。
  • dequeue(): queue[1] からデータを取り出し、head が 1 増えて 2 になる。
  • enqueue(40): queue[4] に 40 が入り、tail が 1 増えて 5 になる。

以上より、最終的な値は head = 2, tail = 5 となります。

第3問（本番レベル・リングバッファ）

第2問のような単純な配列実装では、enqueue と dequeue を繰り返すと、配列の前方に空きがあるのに tail が配列の末尾に到達してしまい、データを追加できなくなります。

これを防ぐため、配列の末尾の次は再び先頭に戻る「リングバッファ（循環配列）」の仕組みを用います。

要素数 N の配列（インデックスは 0 から N-1）でリングバッファを実装しているとします。現在 tail は配列の末尾である N-1 を指しています。この状態で新しくデータを enqueue した場合、データを格納した後の新しい tail の値を計算する式として適切なものはどれでしょうか。（※配列は満杯ではないとします）

第3問 解答と解説

正解： イ ((tail + 1) % N)

リングバッファでは、配列の最後まで到達したらインデックスを 0 に戻す必要があります。

% は割り算の余り（剰余）を求める演算子です。tail を1増やして要素数 N で割った余りを求めることで、循環させることができます。

  • 例えば要素数 N = 5（インデックスは 0〜4）の配列を考えます。
  • 現在 tail = 4（末尾）だとします。
  • 次に格納する位置は、単純に tail + 1 をすると 5 になってしまい、配列の範囲外エラーになります。
  • しかし、(tail + 1) % N すなわち (4 + 1) % 5 を計算すると、5 % 5 = 0 となり、無事に先頭のインデックス 0 に戻すことができます。
  • 途中のインデックス（例えば tail = 2）の時は、(2 + 1) % 5 = 3 となり、そのまま通常の「+1」と同じ動きをします。

この 剰余演算（%）を用いたインデックスの循環 は、本番試験のアルゴリズム穴埋め問題で頻出のテクニックです。
