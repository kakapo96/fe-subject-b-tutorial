第1問（基礎トレース）

要素が昇順に格納された配列 data = {10, 30, 50, 70, 90} （要素番号は1〜5）に対して、以下の2分探索プログラムを実行し、target = 70 を探します。

1回目の while ループ処理内で、変数 middle が計算され、条件分岐（if 〜 endif）の処理を終えた直後の、変数 low と high の値の組み合わせとして正しいものはどれか。

〇整数型の配列: data ← {10, 30, 50, 70, 90}
〇整数型: target ← 70
〇整数型: low, high, middle
〇整数型: ans

low ← 1
high ← 5
ans ← -1

while (low <= high)
    middle ← (low + high) ÷ 2 の商
    if (data[middle] == target)
        ans ← middle
        break
    elseif (data[middle] < target)
        low ← middle + 1
    else
        high ← middle - 1
    endif
endwhile

第1問 解答と解説

正解： エ (low = 4, high = 5)

1回目のループでの変数の変化をトレースします。

  • 初期状態: low = 1, high = 5
  • 1回目のループ開始:
    • middle ← (1 + 5) ÷ 2 の商 なので、middle = 3 となります。
    • data[3] は 50 です。
    • target は 70 なので、data[middle] == target (50 == 70) は偽です。
    • 次に elseif (data[middle] < target) を評価します。(50 < 70) は真です。
    • したがって、low ← middle + 1 が実行され、low ← 3 + 1 = 4 となります。
    • high の値は変更されず 5 のままです。

よって、1回目のループの分岐処理が終わった直後の値は low = 4, high = 5 となります。

第2問（発展トレース）

昇順に格納された配列 data = {12, 25, 36, 48, 55, 62, 79, 81, 95} （要素番号1〜9）から target = 25 を、第1問と同じ2分探索プログラムを用いて探索します。

探索が完了して変数 ans に発見した要素番号が代入されるのは、while ループの処理を何回目に実行したときでしょうか。

第2問 解答と解説

正解： イ (2回目)

ループごとの変数の変化をトレースします。

  • 初期状態: low = 1, high = 9
  • 1回目のループ:
    • middle ← (1 + 9) ÷ 2 の商 = 5
    • data[5] は 55 です。
    • target (25) は 55 より小さいので、data[middle] < target は偽です。
    • else ブロックに進み、high ← middle - 1 = 4 に更新されます。(左半分に絞り込み)
  • 2回目のループ:
    • 現在の範囲は low = 1, high = 4 です。
    • middle ← (1 + 4) ÷ 2 の商 = 2
    • data[2] は 25 です。
    • target (25) と完全に一致するため、if (data[middle] == target) が真になります。
    • ans ← 2 が実行され、break でループを抜けます。

以上より、2回目のループで目的の数値が見つかり、処理が終了します。

第3問（本番レベル・穴埋め）

通常、2分探索はデータが昇順（小さい順）に並んでいることを前提としますが、もし配列 data の要素が降順（大きい順）に並んでいた場合、プログラムの条件式を変更する必要があります。

以下の降順データ用2分探索プログラムの空欄 [ a ] に入る適切な条件式を選んでください。

〇整数型の配列: data // 要素は降順(大きい順)に並んでいる
〇整数型: target
〇整数型: low, high, middle
〇整数型: ans

low ← 1
high ← dataの要素数
ans ← -1

while (low <= high)
    middle ← (low + high) ÷ 2 の商
    if (data[middle] == target)
        ans ← middle
        break
    elseif ( [  a  ] )
        // targetの方が大きい場合、左半分に答えがある
        high ← middle - 1
    else
        // targetの方が小さい場合、右半分に答えがある
        low ← middle + 1
    endif
endwhile

第3問 解答と解説

正解： ア (data[middle] < target)

データが降順（大きい順）に並んでいる場合、配列の左側（要素番号が小さい方）に大きい値が、右側に小さい値が格納されています。

  • 例： {90, 70, 50, 30, 10}

コメントにある通り、elseif のブロックは「targetの方が大きい場合」の処理です。
探している target が、真ん中の値 data[middle] よりも大きいということは、条件式としては target > data[middle]、つまり data[middle] < target となります。

降順の配列で、真ん中の値より探している値が大きい場合、その値は真ん中より左側に存在します。そのため、探索範囲の右端を示す high を middle - 1 に移動して左半分に絞り込みます。

逆に target の方が小さい場合は、値は右側に存在するため、else 節で low ← middle + 1 となります。
